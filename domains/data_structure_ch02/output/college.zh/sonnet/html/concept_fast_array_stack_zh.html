快速数组栈

定义

栈（Stack）是一种遵循"后进先出"（LIFO，Last In First Out）原则的线性数据结构：最后压入的元素最先弹出，就像一叠餐盘——只能从顶部取放。快速数组栈是用连续内存数组实现栈的方案。与链表栈相比，它避免了频繁的动态内存分配，充分利用 CPU 缓存局部性，使得压栈（push）和弹栈（pop）操作在实践中极快。维护一个整数 top 指向当前栈顶元素的索引，即可完成所有核心操作，时间复杂度均为 $O(1)$。

工作原理

数组在内存中是连续排列的，访问 arr[top] 只需一次地址计算，不存在指针追踪。当数组容量不足时，将容量翻倍（动态扩容），虽然单次扩容需要 $O(n)$，但均摊到每个元素上仍是 $O(1)$，这一结论称为均摊分析。

代码示例

class FastArrayStack:
    def __init__(self, capacity=8):
        self._data = [None] * capacity
        self._top = -1          # -1 表示空栈

    def push(self, val):
        if self._top + 1 == len(self._data):
            self._data *= 2     # 容量翻倍
        self._top += 1
        self._data[self._top] = val

    def pop(self):
        if self._top < 0:
            raise IndexError("栈为空")
        val = self._data[self._top]
        self._data[self._top] = None  # 释放引用，防止内存泄漏
        self._top -= 1
        return val

    def peek(self):
        return self._data[self._top] if self._top >= 0 else None

    def __len__(self):
        return self._top + 1

运行 push(1)、push(2)、push(3)，再 pop() 将依次返回 3、2、1，完全符合 LIFO 语义。

实际应用：括号匹配

给定字符串 "({[]})" ，判断括号是否合法——这是快速数组栈最经典的应用场景。遍历每个字符：遇到左括号压栈；遇到右括号时，弹出栈顶并检验是否匹配；最终栈为空则合法，否则不合法。由于每个字符最多经历一次压栈和一次弹栈，整体时间复杂度为 $O(n)$，空间复杂度为 $O(n)$。
