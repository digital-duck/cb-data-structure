Backing Array

Definition. A backing array is the contiguous block of memory that underlies a dynamic data structure—most commonly a dynamic array or array-based stack—storing the actual elements. The backing array has a fixed capacity $C$ at any moment, while the structure tracks a separate size $n \leq C$ denoting how many positions are currently occupied. When $n$ reaches $C$, the structure allocates a new, larger backing array, copies all elements, and releases the old one. This operation is called a resize or reallocation.

Formally, let $B_k$ denote the backing array after the $k$-th resize, with capacity $C_k$. Under the standard doubling strategy, $C_0 = 1$ and $C_k = 2^k$. Elements at logical indices $0, 1, \ldots, n-1$ reside at physical addresses $\text{base}(B_k) + i \cdot w$, where $w$ is the element width in bytes, giving $O(1)$ random access.

Worked Example. Suppose we append the sequence $[10, 20, 30, 40, 50]$ to an initially empty dynamic array with $C_0 = 2$.

| Step | Action | $n$ | $C$ | Resize? | |------|--------|-----|-----|---------| | 1 | append 10 | 1 | 2 | No | | 2 | append 20 | 2 | 2 | No | | 3 | append 30 | 3 | 4 | Yes ($C: 2 \to 4$) | | 4 | append 40 | 4 | 4 | No | | 5 | append 50 | 5 | 8 | Yes ($C: 4 \to 8$) |

After all five appends, the backing array holds eight slots, five occupied.

Key Theorem (Amortized $O(1)$ Append). With the doubling strategy, any sequence of $n$ appends starting from an empty structure costs $O(n)$ total time, so the amortized cost per append is $O(1)$.

Proof sketch. The total copy work across all resizes is $\sum_{k=0}^{\lfloor \log_2 n \rfloor} 2^k = 2^{\lfloor \log_2 n \rfloor + 1} - 1 < 2n$. Adding the $n$ individual append costs gives $O(n)$ overall. $\square$

Lab Cell.

from sympy import symbols, summation, ceiling, log, simplify, S

k, n = symbols('k n', positive=True, integer=True)
total_copy_work = summation(2**k, (k, 0, ceiling(log(n, 2))))
print("Total copy work:", simplify(total_copy_work))
# Verify amortized bound: total_copy_work / n → O(1)
print("Ratio to n:", simplify(total_copy_work / n))

Running this cell confirms that total copy work grows as $\Theta(n)$, validating the amortized analysis symbolically.
