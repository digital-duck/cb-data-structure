List Interface

Definition. A list interface is an abstract specification of a sequential container that supports ordered storage and retrieval of elements by position. Formally, let $S$ be a set of elements and $\mathbb{Z}_{\geq 0}$ the set of non-negative integers. A list $L$ of length $n$ is a total function

$$L : \{0, 1, \ldots, n-1\} \longrightarrow S,$$

where $L(i)$ denotes the element at index $i$. The interface exposes a minimal set of operations — commonly $\texttt{get}(i)$, $\texttt{set}(i, x)$, $\texttt{insert}(i, x)$, and $\texttt{delete}(i)$ — along with the invariant that indices remain contiguous after every mutation. The distinction between an interface and an implementation is fundamental: the interface describes what the operations must do, while concrete data structures (arrays, linked lists) specify how they are realized with particular time and space trade-offs.

Worked Example. Consider the list $L = [7, 3, 9, 1]$, so $n = 4$ and $L(0) = 7,\, L(2) = 9$. Executing $\texttt{insert}(1, 5)$ yields $L' = [7, 5, 3, 9, 1]$ with $n' = 5$. Formally, the new function satisfies

$$L'(i) = \begin{cases} L(i) & i < 1, \\ 5 & i = 1, \\ L(i-1) & i > 1. \end{cases}$$

Every element at index $\geq 1$ is shifted right by one, preserving the contiguity invariant.

Key Theorem (Index-Shift Invariant). Let $L$ be a list of length $n$. After $\texttt{insert}(k, x)$ for any $0 \leq k \leq n$, the resulting list $L'$ has length $n+1$, and for all $i \in \{0,\ldots,n\}$:

$$L'(i) = \begin{cases} L(i) & 0 \leq i < k, \\ x & i = k, \\ L(i-1) & k < i \leq n. \end{cases}$$

Proof sketch. Define $L'$ by the three cases above. Totality on $\{0,\ldots,n\}$ follows because the cases partition the index domain. Contiguity is immediate by construction. $\square$

Lab Cell.

from sympy import symbols, Function, Piecewise, Integer

# Represent the list as a Python list and verify the index-shift invariant
L = [7, 3, 9, 1]
k, x = 1, 5

L_prime = L[:k] + [x] + L[k:]          # insert at position k
expected = {i: (L[i] if i < k else (x if i == k else L[i-1]))
            for i in range(len(L) + 1)}

assert all(L_prime[i] == expected[i] for i in range(len(L_prime))), \
    "Index-shift invariant violated"

print("L      =", L)
print("L'     =", L_prime)
print("L'[k]  =", L_prime[k], "  (inserted element)")
