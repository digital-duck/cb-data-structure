Resize Operation

Definition. Let $A$ be an array (tensor) with shape $\mathbf{s} = (s_1, s_2, \ldots, s_n) \in \mathbb{Z}_{>0}^n$, so that the total number of elements is $N = \prod_{i=1}^n s_i$. A resize operation maps $A$ to a new array $B$ with target shape $\mathbf{t} = (t_1, t_2, \ldots, t_m)$, subject to the constraint

$$\prod_{j=1}^m t_j = N.$$

Formally, $\operatorname{resize}(A, \mathbf{t}) = B$ where the bijection between flat indices is given by the identity map: element $A[\,\overline{i}\,]$ at multi-index $\overline{i}$ (read in row-major order) becomes $B[\,\overline{j}\,]$ at the multi-index $\overline{j}$ satisfying $\operatorname{ravel}(\overline{i}, \mathbf{s}) = \operatorname{ravel}(\overline{j}, \mathbf{t})$. Here $\operatorname{ravel}(\overline{i}, \mathbf{s}) = \sum_{k=1}^n i_k \prod_{\ell=k+1}^n s_\ell$ is the standard row-major linearisation. Crucially, resize is a reinterpretation of the same flat data buffer, not an interpolation or sampling; no new values are computed.

Worked Example. Consider the matrix

$$A = \begin{pmatrix} 1 & 2 & 3 \\ 4 & 5 & 6 \end{pmatrix}, \quad \mathbf{s} = (2, 3), \quad N = 6.$$

Flattening row-major yields the sequence $(1, 2, 3, 4, 5, 6)$. Applying $\operatorname{resize}(A, (3, 2))$ regroups this sequence into three rows of two:

$$B = \begin{pmatrix} 1 & 2 \\ 3 & 4 \\ 5 & 6 \end{pmatrix}, \quad \mathbf{t} = (3, 2).$$

Note that $B[1, 0] = 3 = A[0, 2]$, consistent with both having flat index $2$.

Key Theorem (Shape Equivalence). Two shapes $\mathbf{s}$ and $\mathbf{t}$ admit a resize operation between them if and only if $\prod_{i} s_i = \prod_{j} t_j$. Moreover, $\operatorname{resize}(\operatorname{resize}(A, \mathbf{t}), \mathbf{s}) = A$ for all valid $\mathbf{t}$, so the operation is its own inverse with appropriate target shape. This follows immediately from the bijectivity of $\operatorname{ravel}$ on finite index sets of equal cardinality.

Lab Cell.

from sympy import Array, reshape

A = Array([[1, 2, 3], [4, 5, 6]])   # shape (2, 3)
B = reshape(A, (3, 2))              # resize to shape (3, 2)
print(B)                            # [[1, 2], [3, 4], [5, 6]]

# Verify round-trip identity
assert reshape(B, (2, 3)) == A

Running this cell confirms both the reshaped output and the round-trip guarantee, grounding the theorem in a directly executable verification.
