底层数组

你已经知道动态数组（比如 Python 的列表）可以随时添加元素，好像它的容量是无限的。但计算机内存并不是魔法——每一块存储空间都必须提前申请。那么，动态数组是怎么做到"弹性伸缩"的呢？

真正的结构

动态数组背后藏着一个普通的固定长度数组，这就叫做底层数组（backing array）。它记录两个关键数字：

  • $n$：当前实际存储的元素个数
  • $\text{capacity}$：底层数组的总容量

    • 只要 $n < \text{capacity}$，添加元素就只是把值写进下一个空位，速度极快。

    当 $n = \text{capacity}$ 时，空间用完了。这时系统会申请一块更大的新数组（通常是原来的 $2$ 倍），把所有元素复制过去，再丢弃旧数组。这个过程叫做扩容（resize）。

    简单规律

    每次扩容后，新容量变为 $2 \times \text{capacity}$。虽然复制一次要花 $O(n)$ 的时间，但由于扩容越来越少发生，平均到每次添加操作，代价只有 $O(1)$。这个结论叫做摊还分析，是算法中一个很优雅的思想。

    练习题

    一个底层数组的初始容量为 $4$，每次扩容变为原来的 $2$ 倍。依次插入 $9$ 个元素，请列出每次扩容时的旧容量、新容量，以及总共发生了几次扩容？
