栈操作与单链表（SLList）

栈是一种"后进先出"（LIFO）的数据结构：最后压入的元素最先被弹出。单链表（SLList）只保存头指针 head，每个结点包含 value 与 next。若把表头当作栈顶，则两种操作都只需改动常数个指针：

  • push(x)：创建新结点，令其 next 指向原头结点，再把 head 指向新结点。
  • pop()：若表为空则报错；否则取出 head.value，再令 head = head.next。

    • 二者都不需要遍历链表，所以与元素个数 $n$ 无关，时间均为 $O(1)$。

    例题：逐步追踪

    从空栈开始，依次执行 push(3)、push(7)、push(5)、pop()。

  • push(3)：$\text{head}\to[3]\to\varnothing$
  • push(7)：$\text{head}\to[7]\to[3]\to\varnothing$
  • push(5)：$\text{head}\to[5]\to[7]\to[3]\to\varnothing$
  • pop()：返回 $5$，$\text{head}\to[7]\to[3]\to\varnothing$
    • class Node:
    def __init__(self, value, next=None):
        self.value, self.next = value, next

class SLStack:
    def __init__(self):
        self.head = None
        self.n = 0

    def push(self, x):
        self.head = Node(x, self.head)   # 新结点指向旧头
        self.n += 1

    def pop(self):
        if self.head is None:
            raise IndexError("pop from empty stack")
        x = self.head.value
        self.head = self.head.next       # 头指针后移
        self.n -= 1
        return x

    每个方法只含固定数量的赋值与比较，因此最坏情况下也是 $T(n)=c=O(1)$。

    为什么选择表头而不是表尾？

    若把表尾当作栈顶，push 还可以借助尾指针做到 $O(1)$，但 pop 必须找到倒数第二个结点，而单链表没有反向指针，只能从头遍历，代价为 $\Theta(n)$。所以单链表的栈必须放在表头。

    问题求解应用：括号匹配

    判断字符串 "{[()]}" 是否括号匹配：遇到左括号就 push；遇到右括号就 pop，并检查弹出的括号是否与之配对；扫描结束时栈必须为空。

    def balanced(s):
    pair = {')': '(', ']': '[', '}': '{'}
    st = SLStack()
    for ch in s:
        if ch in '([{':
            st.push(ch)
        elif ch in pair:
            if st.n == 0 or st.pop() != pair[ch]:
                return False
    return st.n == 0

    对长度为 $m$ 的字符串，每个字符至多触发一次 $O(1)$ 的栈操作，总时间为 $O(m)$。对 "([)]"，读到 ) 时弹出的是 [，与 ( 不配对，返回 False。

    小结

    | 操作 | 修改位置 | 时间 | |---|---|---| | push(x) | 表头插入 | $O(1)$ | | pop() | 表头删除 | $O(1)$ |

    要点：把栈顶对应到单链表能在常数时间内访问和修改的一端，也就是表头，这样两种操作的代价都与 $n$ 无关。
