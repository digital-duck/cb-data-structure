Concept Book: Xor List

Data Structure Ch03 · Generated by SPL

Payoff

Throughout this text, we have built toward a single unifying construction. Having examined bitwise algebra, pointer arithmetic, and the structural constraints imposed by linear data organization, we are now positioned to appreciate what the XOR-linked list (xor_list) actually accomplishes and why it constitutes a natural—indeed, almost inevitable—culmination of these ideas.

What xor_list achieves. A conventional doubly linked list allocates two pointer fields per node: one for the predecessor and one for the successor. The XOR-linked list collapses these into a single field by storing the value

$$\text{npx}(v) = \text{addr}(\text{prev}(v)) \oplus \text{addr}(\text{next}(v)),$$

where $\oplus$ denotes bitwise XOR and $\text{addr}(\cdot)$ maps a node to its memory address. The key algebraic fact is that XOR is its own inverse: given any one neighbor's address $a$, the other is recovered by

$$a' = \text{npx}(v) \oplus a.$$

Traversal in either direction therefore requires only one address carried from the previous step, not a stored back-pointer. The structure achieves full bidirectional traversal at exactly half the pointer overhead of a naive doubly linked list—$O(1)$ extra space per node, no asymptotic penalty on any operation.

A worked example. Suppose three nodes $A$, $B$, $C$ have addresses $0\mathrm{x}10$, $0\mathrm{x}20$, $0\mathrm{x}30$. Node $B$ stores $\text{npx}(B) = 0\mathrm{x}10 \oplus 0\mathrm{x}30 = 0\mathrm{x}20$. Arriving at $B$ from $A$ (holding $\text{addr}(A) = 0\mathrm{x}10$), we compute $\text{next} = 0\mathrm{x}20 \oplus 0\mathrm{x}10 = 0\mathrm{x}30$, which is exactly $\text{addr}(C)$. The arithmetic recovers directionality from nothing more than the entry point.

Key theorem. Let $L$ be an XOR-linked list of $n$ nodes. Forward and backward traversal each require $O(n)$ time and $O(1)$ auxiliary space, identical to a conventional doubly linked list, while total pointer storage is reduced from $2n$ to $n$ words.

Lab cell (SymPy).

from sympy import symbols, Xor, simplify_logic

a, b = symbols('a b', integer=True)
# Verify self-inverse: (a XOR b) XOR a == b
expr = Xor(Xor(a, b), a)
print(simplify_logic(expr))   # prints b

This single identity is the engine of the entire construction.

The connections xor_list forges—across memory systems, error-correcting codes, hardware cache design, and the algebraic theory of groups—each deserves its own investigation.
