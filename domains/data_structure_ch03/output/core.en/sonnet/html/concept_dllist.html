Dllist

Definition. A doubly linked list (dllist) is a linear data structure consisting of a sequence of nodes $N_1, N_2, \ldots, N_n$, where each node $N_i$ stores three fields: a data element $d_i$, a pointer $\text{next}_i$ to the successor node $N_{i+1}$, and a pointer $\text{prev}_i$ to the predecessor node $N_{i-1}$. Boundary sentinels are defined by $\text{prev}_1 = \text{null}$ and $\text{next}_n = \text{null}$. Formally, a dllist of length $n$ is a tuple

$$L = \bigl(N_1, N_2, \ldots, N_n\bigr), \quad N_i = (d_i,\, \text{prev}_i,\, \text{next}_i),$$

where pointer consistency requires $\text{next}_i = N_{i+1}$ and $\text{prev}_{i+1} = N_i$ for all $1 \le i < n$.

The bidirectional linkage distinguishes the dllist from a singly linked list, enabling $O(1)$ traversal in either direction from any node.

Worked Example. Consider the list $L = (3, 7, 12)$. The three nodes are

$$N_1 = (3, \text{null}, N_2), \quad N_2 = (7, N_1, N_3), \quad N_3 = (12, N_2, \text{null}).$$

To delete $N_2$ in place, reassign two pointers: set $\text{next}_1 \leftarrow N_3$ and $\text{prev}_3 \leftarrow N_1$. Node $N_2$ is then unreachable from $L$, and no element shifts position. The resulting list $L' = (3, 12)$ satisfies pointer consistency with exactly two pointer writes, independent of $n$.

Key Theorem (Insertion and Deletion Complexity). In a dllist with a direct reference to node $N_i$, both insertion of a new node immediately after $N_i$ and deletion of $N_i$ execute in $\Theta(1)$ time and $\Theta(1)$ auxiliary space.

Proof sketch. Each operation requires updating at most four pointer fields (two on the target node, one each on its neighbors). Because no iteration over the list is performed, the number of operations is bounded by a constant independent of $n$. $\square$

This contrasts with arrays, for which insertion or deletion at an arbitrary interior position costs $\Theta(n)$ due to element shifting.

Lab Cell (SymPy).

from sympy import symbols, Eq, solve

# Represent node addresses symbolically and verify pointer consistency
prev1, next1, prev2, next2, prev3, next3 = symbols(
    'prev1 next1 prev2 next2 prev3 next3')

N1, N2, N3 = 1, 2, 3   # integer stand-ins for addresses

constraints = [
    Eq(next1, N2), Eq(prev2, N1),   # N1 <-> N2
    Eq(next2, N3), Eq(prev3, N2),   # N2 <-> N3
]

solution = solve(constraints, [next1, prev2, next2, prev3])
print("Pointer assignments:", solution)

# Simulate deletion of N2
next1_after = N3
prev3_after = N1
print(f"After deleting N2: next(N1)={next1_after}, prev(N3)={prev3_after}")
assert next1_after == prev3_after - 1 + 1  # consistency trivially holds
print("Pointer consistency verified.")
