Dllist List Operations

A doubly linked list (DLL) is a linear data structure in which each node stores a data element together with two pointers: one to its successor and one to its predecessor. Formally, a DLL of $n$ elements is a tuple $(N, \text{prev}, \text{next}, \text{head}, \text{tail})$ where $N = \{v_1, v_2, \ldots, v_n\}$ is a set of nodes, $\text{next}(v_i) = v_{i+1}$ for $i < n$, $\text{prev}(v_i) = v_{i-1}$ for $i > 1$, and the sentinel values $\text{prev}(v_1) = \text{next}(v_n) = \texttt{None}$ delimit the list. The fundamental operations are insertion, deletion, and traversal, each acting on this pointer structure.

Worked Example. Consider the list $L = [10 \leftrightarrow 20 \leftrightarrow 30]$. To insert the value $15$ after node $v_1$ (holding $10$), execute the following pointer assignments in order:

$$ \text{new.prev} \leftarrow v_1, \quad \text{new.next} \leftarrow v_2, \quad v_1.\text{next} \leftarrow \text{new}, \quad v_2.\text{prev} \leftarrow \text{new}. $$

After insertion, $L = [10 \leftrightarrow 15 \leftrightarrow 20 \leftrightarrow 30]$. Deletion of $v_2$ (holding $20$) from the updated list requires only two reassignments: $v_1.\text{next} \leftarrow v_3$ and $v_3.\text{prev} \leftarrow v_1$, after which node $v_2$ is unreachable and may be reclaimed by the garbage collector.

Key Theorem (Constant-Time Local Operations). For a DLL in which a direct reference to the target node is given, insertion and deletion each complete in $\Theta(1)$ time, independent of list length $n$. This contrasts with a singly linked list, where deletion requires $\Theta(n)$ traversal to locate the predecessor. Forward and backward traversal each require $\Theta(n)$ time, and random access to the $k$-th element costs $\Theta(\min(k,\, n-k))$ by choosing the nearer end.

Lab Cell.

from llist import dllist   # pip install llist

L = dllist([10, 20, 30])
node20 = L.nodeat(1)       # O(k) lookup
L.insertafter(dllist([15]).first, node20.prev)
print(list(L))             # [10, 15, 20, 30]

L.remove(node20)
print(list(L))             # [10, 15, 30]

# Verify backward linkage
node = L.last
while node is not None:
    print(node.value, end=' ')
    node = node.prev       # 30 15 10

The bidirectional pointer structure makes DLLs the natural substrate for algorithms requiring efficient insertion and deletion at arbitrary interior positions, such as LRU cache eviction and text-editor cursor buffers.
