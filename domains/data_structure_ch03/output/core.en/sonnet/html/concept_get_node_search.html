Get Node Search

Definition. Let $G = (V, E)$ be a directed or undirected graph with vertex set $V$ and edge set $E \subseteq V \times V$. A node search is a function

$$\text{get\_node\_search} : G \times q \;\longrightarrow\; S \subseteq V,$$

where $q$ is a query predicate — a Boolean-valued function $q : V \to \{\text{true}, \text{false}\}$ — and $S$ is the maximal subset of vertices satisfying $q$. Formally,

$$S = \{ v \in V \mid q(v) = \text{true} \}.$$

The predicate $q$ may test any attribute of a vertex: its label, an attached scalar weight, membership in a neighborhood, or a compound logical condition formed by conjunction ($\wedge$), disjunction ($\vee$), or negation ($\neg$) of simpler tests.

Worked Example. Consider the graph $G$ with five labeled vertices

$$V = \{\texttt{alpha},\, \texttt{beta},\, \texttt{gamma},\, \texttt{alpha\_prime},\, \texttt{delta}\}$$

and edges connecting them in a chain. Suppose each vertex $v$ carries a real weight $w(v)$, with values $\{3.1,\, 7.4,\, 2.0,\, 5.5,\, 7.4\}$ respectively. Define the compound predicate

$$q(v) \;=\; \bigl(\text{label}(v) \text{ contains } \texttt{"alpha"}\bigr) \;\vee\; \bigl(w(v) > 6.0\bigr).$$

Evaluating $q$ on each vertex:

| Vertex | Label test | Weight test | $q(v)$ | |---|---|---|---| | $\texttt{alpha}$ | true | false | true | | $\texttt{beta}$ | false | true | true | | $\texttt{gamma}$ | false | false | false | | $\texttt{alpha\_prime}$ | true | false | true | | $\texttt{delta}$ | false | true | true |

Thus $S = \{\texttt{alpha},\, \texttt{beta},\, \texttt{alpha\_prime},\, \texttt{delta}\}$.

Key Theorem (Linear Search Complexity). For a graph $G = (V, E)$ whose vertex attributes are stored in a flat index, evaluating $\text{get\_node\_search}$ requires $\Theta(|V|)$ time, since every vertex must be tested against $q$ exactly once. If vertex attributes are indexed by a balanced binary search tree or hash map on a single key, queries restricted to that key reduce to $O(\log |V|)$ or $O(1)$ expected time, respectively. No assumption on $|E|$ is required: node search is purely a vertex-level operation and is independent of edge traversal.

Lab Cell (SymPy / NetworkX).

import networkx as nx

G = nx.Graph()
nodes = [
    ("alpha",       {"weight": 3.1}),
    ("beta",        {"weight": 7.4}),
    ("gamma",       {"weight": 2.0}),
    ("alpha_prime", {"weight": 5.5}),
    ("delta",       {"weight": 7.4}),
]
G.add_nodes_from(nodes)

def predicate(v, data):
    return ("alpha" in v) or (data.get("weight", 0) > 6.0)

result = [v for v, d in G.nodes(data=True) if predicate(v, d)]
print(result)  # ['alpha', 'beta', 'alpha_prime', 'delta']

Experiment: replace the disjunction with a conjunction ($\wedge$) and observe how the result set $S$ shrinks. This illustrates that the complexity theorem holds regardless of predicate complexity — only $|V|$ vertex evaluations occur.
