Queue Operations Sllist

Definition. A queue is an abstract data type that maintains a collection of elements subject to the first-in, first-out (FIFO) discipline: the element inserted earliest is the first to be removed. Formally, a queue $Q$ supports four primitive operations:

  • $\texttt{enqueue}(Q, x)$: append element $x$ to the tail of $Q$.
  • $\texttt{dequeue}(Q)$: remove and return the element at the head of $Q$.
  • $\texttt{peek}(Q)$: return the head element without removing it.
  • $\texttt{is\_empty}(Q)$: return $\texttt{True}$ if $|Q| = 0$.

    • A singly linked list (SLL) implementation stores each element in a node $v = (\texttt{data}, \texttt{next})$, where $\texttt{next}$ is either a pointer to the successor node or $\texttt{None}$. Two external pointers, $\texttt{head}$ and $\texttt{tail}$, reference the front and back of the list, respectively.

    Worked Example. Begin with an empty queue ($\texttt{head} = \texttt{tail} = \texttt{None}$). Execute the following sequence:

  • $\texttt{enqueue}(Q, 10)$: allocate node $A = (10, \texttt{None})$; set $\texttt{head} = \texttt{tail} = A$.
  • $\texttt{enqueue}(Q, 20)$: allocate node $B = (20, \texttt{None})$; set $A.\texttt{next} = B$ and $\texttt{tail} = B$. The list is $10 \to 20$.
  • $\texttt{dequeue}(Q)$: return $\texttt{head}.\texttt{data} = 10$; advance $\texttt{head} = B$. The list is $20$.

    • After the sequence, $\texttt{peek}(Q) = 20$ and $|Q| = 1$.

    Key Theorem (Constant-Time Operations). With explicit $\texttt{head}$ and $\texttt{tail}$ pointers, every queue operation on an SLL runs in $O(1)$ worst-case time. $\texttt{enqueue}$ appends by updating $\texttt{tail}.\texttt{next}$ and advancing $\texttt{tail}$—a fixed number of pointer assignments. $\texttt{dequeue}$ reads $\texttt{head}.\texttt{data}$ and advances $\texttt{head}$—likewise $O(1)$. No traversal of the list is required in either case, so the time bound is independent of $|Q|$.

    from sympy import symbols, Function, oo

class Node:
    def __init__(self, data):
        self.data, self.next = data, None

class SLLQueue:
    def __init__(self):
        self.head = self.tail = None
        self._size = 0

    def enqueue(self, x):
        node = Node(x)
        if self.tail:
            self.tail.next = node
        else:
            self.head = node
        self.tail = node
        self._size += 1

    def dequeue(self):
        if not self.head:
            raise IndexError("dequeue from empty queue")
        val = self.head.data
        self.head = self.head.next
        if not self.head:
            self.tail = None
        self._size -= 1
        return val

q = SLLQueue()
for v in [10, 20, 30]:
    q.enqueue(v)
print([q.dequeue() for _ in range(3)])  # [10, 20, 30]

    The output $[10, 20, 30]$ confirms FIFO ordering: elements are returned in the exact sequence they were inserted.
