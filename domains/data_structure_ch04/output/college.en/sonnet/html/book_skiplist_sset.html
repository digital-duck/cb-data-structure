Concept Book: Skiplist Sset

Data Structure Ch04 · Generated by SPL

Payoff

The skiplist_sset is where the book's threads meet. An SSet (sorted set) must support add(x), remove(x), and find(x), where find(x) returns the smallest stored element $y \ge x$. A sorted array finds quickly but inserts slowly. A linked list inserts quickly but searches slowly. The skiplist removes the trade-off with randomness. Each node is promoted to the next level with probability $\tfrac12$, so its height $h$ is geometric: $\Pr[h \ge k] = 2^{-k}$. The expected number of nodes at level $k$ is $n/2^k$, and the structure has about $\log_2 n$ levels.

Why it is the natural endpoint. A search starts at the top level, moves right while the next key is $< x$, then drops down a level. Reading the path backward from the target, each step goes up with probability $\tfrac12$ and left with probability $\tfrac12$. Reaching the bottom level therefore takes about $2$ steps per level, so the expected cost is

$$\mathbb{E}[\text{search length}] \le 2\log_2 n + O(1).$$

Insertion and deletion cost $O(\log n)$ expected time, because they are a search plus $O(1)$ expected pointer updates. Expected space is $\sum_k n/2^k = 2n$ pointers. The guarantee holds for every input order, because the randomness comes from the coin flips and not from the data. This reuses the earlier ideas: linked lists, the geometric distribution, expectation by linearity, and the logarithmic recurrences that make divide-and-conquer fast.

Worked check. Take $n = 1024$. The expected height is about $\log_2 1024 = 10$, so a search takes roughly $2 \cdot 10 = 20$ steps. A plain linked list would average about $512$ comparisons.

Connections to applications. The list of unlocked applications is empty here, so these are the domains where this structure is typically used.

  • Ordered indexes and databases. Range queries use find(x) to locate the start, then walk the bottom list. Redis sorted sets and LevelDB/RocksDB memtables use skiplists for this.
  • Concurrent systems. Inserting a node touches only a few local pointers, so lock-free versions are simpler than the rotations a balanced tree needs. Java's ConcurrentSkipListMap is one example.
  • Scheduling and priority structures. The first bottom-level node is the minimum, which gives a priority queue with efficient deletion of arbitrary elements.
  • Distributed systems. The same layered "express lane" idea appears in skip graphs and overlay networks for peer-to-peer lookup.
