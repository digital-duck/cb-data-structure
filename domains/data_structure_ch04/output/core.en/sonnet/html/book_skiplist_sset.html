What the Journey Has Built

Every concept introduced in the preceding chapters — probability, geometric series, linked structures, amortized analysis — converges here. A skiplist sorted set (skiplist_sset) is a randomized linked-list hierarchy that maintains a totally ordered dynamic set supporting search, insertion, and deletion each in expected $O(\log n)$ time and $O(n)$ expected space, without the rotations or rebalancing machinery that balanced binary search trees require.

Formally, a skiplist on a universe $(U, \leq)$ consists of a sequence of linked lists $L_0 \supseteq L_1 \supseteq \cdots \supseteq L_h$, where $L_0$ contains every stored key and each key in $L_i$ is independently promoted to $L_{i+1}$ with probability $p = \tfrac{1}{2}$. A sentinel $-\infty$ heads every level. The expected height satisfies $\mathbb{E}[h] = O(\log n)$, and a search for key $x$ descends greedily: advance right while the next key does not exceed $x$, then drop one level.

A Concrete Search

Suppose the set holds $\{3, 7, 12, 19, 26\}$ across three levels. Searching for $19$:

  • At $L_2$: advance past $3$, stop before $26$, drop.
  • At $L_1$: advance past $12$, stop before $26$, drop.
  • At $L_0$: advance to $19$. Found.

    • Total comparisons: $4$, whereas a na\"ive scan of $L_0$ alone would require $4$ steps in the worst case — but the skip structure guarantees this logarithmic behavior in expectation across all inputs.

    The Central Theorem

    > Theorem. In a skiplist storing $n$ keys with promotion probability $p = \tfrac{1}{2}$, the expected number of comparisons performed during a search, insertion, or deletion is $O(\log n)$.

    The proof rests on a backwards analysis: tracing the search path in reverse reveals a sequence of independent coin flips, whose expected length is bounded by $2\log_2 n + O(1)$.

    Lab Cell

    from sympy import symbols, Sum, oo, simplify, Rational

k = symbols('k', nonneg=True, integer=True)
p = Rational(1, 2)
# Expected number of levels climbed before first heads
E_climb = Sum(k * p**k * (1 - p), (k, 0, oo))
print(simplify(E_climb.doit()))  # → 1

    Running this cell confirms the geometric-series backbone: at each level boundary, the expected additional climb cost is exactly $1$, so across $\log_2 n$ levels the total is $O(\log n)$.

    The Natural Endpoint

    skiplist_sset is the natural capstone because it unifies every thread: randomness replaces deterministic balancing, amortized bounds become probabilistic ones, and the pointer structure generalises to support rank queries ($k$-th smallest), range scans (all keys in $[a, b]$), and concurrent access with minimal locking — capabilities that underpin database index layers, in-memory caches, and real-time leaderboards alike.
