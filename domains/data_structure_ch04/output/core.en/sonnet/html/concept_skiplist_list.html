Skiplist List

Definition. A skip list is a probabilistic data structure that maintains a sorted sequence of elements across multiple linked layers. Formally, let $S$ be a sorted set of $n$ keys drawn from a totally ordered universe $(\mathcal{U}, \leq)$. A skip list consists of a hierarchy of linked lists $L_0 \supseteq L_1 \supseteq \cdots \supseteq L_h$, where $L_0$ contains every element of $S$ and each element present in $L_i$ is independently promoted to $L_{i+1}$ with probability $p \in (0,1)$, typically $p = \tfrac{1}{2}$. Sentinel nodes $-\infty$ and $+\infty$ bound every level. Each node stores forward pointers to the next node at each level it occupies, enabling logarithmic-time search by skipping over large contiguous segments of $L_0$.

Worked Example. Suppose $S = \{3, 7, 12, 19, 26\}$ and $p = \tfrac{1}{2}$. After construction, a typical three-level skip list might appear as follows:

$$ L_2: \quad -\infty \;\longrightarrow\; 12 \;\longrightarrow\; +\infty $$ $$ L_1: \quad -\infty \;\longrightarrow\; 7 \;\longrightarrow\; 12 \;\longrightarrow\; 19 \;\longrightarrow\; +\infty $$ $$ L_0: \quad -\infty \;\longrightarrow\; 3 \;\longrightarrow\; 7 \;\longrightarrow\; 12 \;\longrightarrow\; 19 \;\longrightarrow\; 26 \;\longrightarrow\; +\infty $$

To search for $19$: begin at $L_2$, advance from $-\infty$ to $12$ (since $26 > 19$), drop to $L_1$, advance to $19$, and confirm at $L_0$. The search traverses only four comparisons rather than five.

Key Theorem (Expected Complexity). For a skip list on $n$ elements with promotion probability $p$, the expected number of comparisons during a search, insertion, or deletion is $O(\log n)$. More precisely, the expected number of levels examined is at most $\log_{1/p} n + \tfrac{1}{1-p}$, and each level contributes an expected constant number of forward steps. Space usage is $O(n)$ in expectation, since the expected total number of node-level pairs is $n \cdot \sum_{i=0}^{\infty} p^i = \tfrac{n}{1-p}$.

Lab Cell.

from sortedcontainers import SortedList

sl = SortedList([3, 7, 12, 19, 26])
sl.add(15)
print(list(sl))           # [3, 7, 12, 15, 19, 26]
idx = sl.bisect_left(19)
print(f"19 found at index {idx}")   # 4
sl.remove(7)
print(list(sl))           # [3, 12, 15, 19, 26]

SortedList exposes the skip-list interface; bisect_left mirrors the top-down search described above, returning the leftmost index where the query key would be inserted to preserve sorted order.
