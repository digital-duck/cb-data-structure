Concept Book: Tree Balancing Strategies

Data Structure Ch06 · Generated by SPL

Payoff

Throughout this chapter we have built a hierarchy of ideas: binary search trees encode ordered data in a recursive structure; traversal algorithms exploit that structure to achieve logarithmic search; and rotation operations preserve the binary-search-tree invariant while rearranging nodes. Tree balancing strategies are the capstone that ties these threads together. A balancing strategy is a policy — a set of structural invariants together with the rebalancing procedures that restore them after every mutation — that guarantees the height $h$ of a tree on $n$ keys satisfies $h = O(\log n)$. Without such a policy the height can degrade to $\Theta(n)$ under adversarial or sorted insertion, collapsing every logarithmic guarantee to linear time.

To make this concrete, consider inserting the sequence $1, 2, 3, 4, 5$ into an unbalanced BST. Each new key is strictly greater than all predecessors, so the tree degenerates into a right-leaning chain of height $4$. A search for key $5$ requires five comparisons — no better than a linked list. An AVL tree, by contrast, enforces the height-balance invariant: for every node $v$, the heights of its left and right subtrees differ by at most one. After inserting $3$ into the right child of $2$, the balance factor of node $1$ becomes $-2$, triggering a left rotation that promotes $2$ to the root with children $1$ and $3$. Continuing through the sequence yields a tree of height $2$, and the search for $5$ terminates in three comparisons.

Theorem (AVL Height Bound). Let $T$ be an AVL tree on $n \geq 1$ keys. Then $h(T) \leq 1.44\log_2(n+2) - 0.328$. Consequently, every search, insertion, and deletion completes in $O(\log n)$ worst-case time.

Proof sketch. Let $N(h)$ denote the minimum number of nodes in an AVL tree of height $h$. The balance invariant forces $N(h) \geq N(h-1) + N(h-2) + 1$, a recurrence whose solution grows as the Fibonacci sequence, $N(h) = \Theta(\phi^h)$ where $\phi = \tfrac{1+\sqrt{5}}{2}$. Inverting gives $h = O(\log_\phi n)$, and a change of base yields the stated constant. $\square$

from sympy import symbols, Function, rsolve, fibonacci, log, N as num

# Verify the Fibonacci lower bound on N(h)
h = symbols('h', positive=True, integer=True)
# Minimum-node AVL tree of height h contains at least F(h+3) - 1 nodes
print([(k, fibonacci(k+3) - 1) for k in range(8)])

# Compute the height bound for n = 1000
n_val = 1000
bound = 1.44 * log(n_val + 2, 2) - 0.328
print(f"Height bound for n=1000: {num(bound, 4)} (floor = {int(bound)})")

The guarantee $h = O(\log n)$ is not merely an aesthetic endpoint — it is the condition under which every algorithm in this chapter performs as advertised. Database indices, compiler symbol tables, interval scheduling, and geometric range queries all rest on this foundation. Each domain instantiates the same contract: pay $O(\log n)$ per update to preserve balance; collect $O(\log n)$ per query as the dividend. To see how this contract scales to millions of keys under real-world update patterns, turn to the next chapter, where we examine red-black trees and their application to the ordered-map data structures that underpin modern in-memory databases.
