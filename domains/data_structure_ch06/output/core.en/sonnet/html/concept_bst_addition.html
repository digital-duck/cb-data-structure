Bst Addition

Definition. Let $T$ be a binary search tree (BST), a rooted binary tree in which every node $v$ stores a key $k(v)$ satisfying the BST invariant: for every node $v$, all keys in $v$'s left subtree are strictly less than $k(v)$, and all keys in $v$'s right subtree are strictly greater than $k(v)$. The BST addition (insertion) operation takes a key $x \notin T$ and produces a new tree $T' = T \cup \{x\}$ that preserves the BST invariant. Insertion locates the unique position where $x$ must reside—following left or right child pointers according to comparisons with each encountered key—and attaches a new leaf node there.

Worked Example. Consider the BST with keys inserted in order $\{5, 3, 7\}$, yielding a root $5$ with left child $3$ and right child $7$. Insert $x = 4$:

  • Compare $4 < 5$: descend to left child $3$.
  • Compare $4 > 3$: descend to right child of $3$, which is $\mathrm{nil}$.
  • Attach a new node with key $4$ as the right child of $3$.

    • The resulting tree satisfies the BST invariant: $3 < 4 < 5 < 7$.

    Key Theorem (Correctness of BST Insertion). If $T$ satisfies the BST invariant before insertion of key $x$, then $T' = \mathrm{insert}(T, x)$ satisfies the BST invariant.

    Proof sketch. The algorithm traverses a root-to-leaf path $v_1, v_2, \ldots, v_d$ determined entirely by comparisons with $x$. At each step, moving left records $x < k(v_i)$ and moving right records $x > k(v_i)$. These comparisons partition the existing keys into sets that are provably less than or greater than $x$, so placing a new leaf at position $v_{d+1}$ violates no existing ordering constraint. Formally, an inductive argument on tree height establishes the invariant for every subtree. $\square$

    The time complexity of a single insertion is $O(h)$, where $h$ is the tree height. For a balanced BST, $h = O(\log n)$, giving efficient $O(\log n)$ insertion.

    Lab Cell (SymPy).

    from sympy import symbols, Function

class BSTNode:
    def __init__(self, key):
        self.key, self.left, self.right = key, None, None

def bst_insert(root, x):
    if root is None:
        return BSTNode(x)
    if x < root.key:
        root.left = bst_insert(root.left, x)
    elif x > root.key:
        root.right = bst_insert(root.right, x)
    return root

def inorder(node, result=None):
    if result is None:
        result = []
    if node:
        inorder(node.left, result)
        result.append(node.key)
        inorder(node.right, result)
    return result

root = None
for k in [5, 3, 7, 4]:
    root = bst_insert(root, k)

print(inorder(root))  # [3, 4, 5, 7] — sorted, confirming BST invariant

    The inorder traversal yields keys in sorted order, providing an empirical check that the BST invariant holds after every insertion.
