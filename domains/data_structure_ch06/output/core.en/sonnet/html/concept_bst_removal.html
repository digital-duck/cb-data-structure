Bst Removal

Definition. Given a binary search tree $T$ and a key $k$, BST removal produces a new tree $T'$ that contains every node of $T$ except the node with key $k$, while preserving the BST invariant: for every node $n$ with left subtree $L$ and right subtree $R$,

$$\forall x \in L,\; x.\mathit{key} < n.\mathit{key} \quad \text{and} \quad \forall y \in R,\; y.\mathit{key} > n.\mathit{key}.$$

Removal is handled by three cases determined by the number of children of the target node $v$:

  • Leaf node ($v$ has no children): delete $v$ directly.
  • One child: replace $v$ with its sole child; the subtree rooted there already satisfies the BST invariant.
  • Two children: find $v$'s in-order successor $s$ — the minimum-key node in $v$'s right subtree — copy $s.\mathit{key}$ into $v$, then recursively remove $s$ from the right subtree. Because $s$ is a minimum, it has no left child, so this recursive call falls into case 1 or 2.

    • Worked example. Consider the BST with keys $\{10, 5, 15, 3, 7, 12, 20\}$ and root $10$. Remove $k = 15$ (a two-child node). Its right subtree contains $\{20\}$ and its left subtree contains $\{12\}$, so the in-order successor is $s = 12$. Copy $12$ into the node formerly holding $15$, then delete the original node holding $12$ (a leaf). The resulting tree has root $10$, left child $5$, and right child $12$ (with right child $20$). Verify: $10 < 12 < 20$ along the right spine — the invariant holds.

    Key theorem (correctness). Let $T$ be a BST satisfying the BST invariant and let $v$ be the node with key $k$. The tree $T'$ produced by the three-case procedure above satisfies the BST invariant and contains exactly the keys $\mathit{keys}(T) \setminus \{k\}$.

    Proof sketch. Cases 1 and 2 preserve the invariant locally by direct substitution. For case 3, the in-order successor $s$ satisfies $v.\mathit{key} < s.\mathit{key} \leq y$ for every $y$ in $v$'s right subtree, so replacing $v.\mathit{key}$ with $s.\mathit{key}$ maintains the ordering between the left subtree, the new root key, and the right subtree. $\blacksquare$

    The worst-case time complexity is $O(h)$ where $h$ is the tree height; for a balanced BST this gives $O(\log n)$.

# Lab: trace BST removal symbolically
class BSTNode:
    def __init__(self, key, left=None, right=None):
        self.key, self.left, self.right = key, left, right

def bst_remove(node, k):
    if node is None:
        return None
    if k < node.key:
        node.left = bst_remove(node.left, k)
    elif k > node.key:
        node.right = bst_remove(node.right, k)
    else:                                  # found target
        if node.left is None:
            return node.right
        if node.right is None:
            return node.left
        # two children: find in-order successor
        s = node.right
        while s.left:
            s = s.left
        node.key = s.key
        node.right = bst_remove(node.right, s.key)
    return node

def inorder(node):
    return inorder(node.left) + [node.key] + inorder(node.right) if node else []

root = BSTNode(10, BSTNode(5, BSTNode(3), BSTNode(7)),
                   BSTNode(15, BSTNode(12), BSTNode(20)))
print("Before:", inorder(root))          # [3, 5, 7, 10, 12, 15, 20]
bst_remove(root, 15)
print("After removing 15:", inorder(root))  # [3, 5, 7, 10, 12, 20]
