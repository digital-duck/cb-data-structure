Bst Search

A binary search tree (BST) is a rooted binary tree in which every node $v$ stores a key $k(v)$ satisfying the BST invariant: for every node $v$, all keys in the left subtree of $v$ are strictly less than $k(v)$, and all keys in the right subtree are strictly greater. Formally, if $L(v)$ and $R(v)$ denote the left and right subtrees, then

$$\forall u \in L(v): k(u) < k(v) \qquad \text{and} \qquad \forall u \in R(v): k(u) > k(v).$$

The BST search procedure locates a target key $t$ by exploiting this invariant. Starting at the root, the algorithm compares $t$ with the current node's key: if $t$ equals the key, the search succeeds; if $t < k(v)$, it recurses into the left subtree; if $t > k(v)$, it recurses into the right subtree. If a null child is reached, $t$ is absent from the tree.

Worked Example. Consider the BST with keys inserted in the order $\{8, 3, 10, 1, 6, 14, 4, 7\}$. The root is $8$. To search for $t = 6$: compare $6 < 8$, move left to $3$; compare $6 > 3$, move right to $6$; keys match — search succeeds after three comparisons. To search for $t = 5$: the path $8 \to 3 \to 6 \to 4$ terminates at the right child of $4$, which is null, so $5$ is not in the tree.

Theorem (Search Complexity). Let $h$ denote the height of a BST on $n$ nodes. BST search runs in $O(h)$ time. For a balanced BST, $h = \Theta(\log n)$, giving $O(\log n)$ worst-case search time. For an unbalanced tree built from a random permutation, the expected height is $O(\log n)$; however, adversarial insertion order can produce $h = \Theta(n)$, degrading search to linear time.

Lab Cell (SymPy).

from sympy.combinatorics.permutations import Permutation

class BSTNode:
    def __init__(self, key):
        self.key, self.left, self.right = key, None, None

def bst_insert(root, key):
    if root is None:
        return BSTNode(key)
    if key < root.key:
        root.left = bst_insert(root.left, key)
    elif key > root.key:
        root.right = bst_insert(root.right, key)
    return root

def bst_search(root, target, depth=0):
    if root is None:
        return None, depth
    if target == root.key:
        return root, depth
    if target < root.key:
        return bst_search(root.left, target, depth + 1)
    return bst_search(root.right, target, depth + 1)

keys = [8, 3, 10, 1, 6, 14, 4, 7]
root = None
for k in keys:
    root = bst_insert(root, k)

node, depth = bst_search(root, 6)
print(f"Found: {node.key}, comparisons: {depth + 1}")  # Found: 6, comparisons: 3

The experiment confirms the three-comparison path derived analytically and invites students to vary the insertion order to observe height growth empirically.
