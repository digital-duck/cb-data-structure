Total Order

Definition. Let $S$ be a non-empty set and let $\leq$ be a binary relation on $S$. The relation $\leq$ is called a total order (or linear order) on $S$ if it satisfies the following four axioms for all $a, b, c \in S$:

  • Reflexivity: $a \leq a$.
  • Antisymmetry: If $a \leq b$ and $b \leq a$, then $a = b$.
  • Transitivity: If $a \leq b$ and $b \leq c$, then $a \leq c$.
  • Totality (Comparability): Either $a \leq b$ or $b \leq a$ (or both).

    • The pair $(S, \leq)$ is called a totally ordered set, or chain. Axioms 1–3 alone define a partial order; it is the totality axiom that distinguishes a total order by demanding every pair of elements be comparable. Consequently, in a totally ordered set one can always arrange elements in a single linear sequence from least to greatest.

    Worked Example. Consider $S = \{2, 5, 3\}$ with the usual $\leq$ on $\mathbb{Z}$. Checking totality: $2 \leq 3$, $2 \leq 5$, $3 \leq 5$. Every pair is comparable, so $(\{2,3,5\}, \leq)$ is a chain with the unique arrangement $2 \leq 3 \leq 5$. Contrast this with the power set $\mathcal{P}(\{1,2\}) = \{\emptyset, \{1\}, \{2\}, \{1,2\}\}$ under inclusion $\subseteq$: neither $\{1\} \subseteq \{2\}$ nor $\{2\} \subseteq \{1\}$, so $\subseteq$ is only a partial order here.

    Key Theorem (Well-Ordering Principle). Every non-empty subset of $\mathbb{N}$ has a least element under the usual $\leq$. More generally, a total order on $S$ is called a well-order if every non-empty subset of $S$ has a least element. Well-ordering underpins mathematical induction and guarantees that recursive algorithms on $\mathbb{N}$ terminate.

    Proof sketch. Suppose $T \subseteq \mathbb{N}$ is non-empty. Let $m = \min T$ be the element obtained by iterating $0, 1, 2, \ldots$ until the first element of $T$ is found; totality ensures this search is unambiguous, and finiteness of the descent guarantees termination. $\square$

    Lab Cell.

    from sympy import symbols, Rational
from sympy.sets import FiniteSet

# Represent the chain {2, 3, 5} and verify pairwise comparability
S = [Rational(2), Rational(3), Rational(5)]
pairs = [(a, b) for a in S for b in S if a != b]
all_comparable = all(a <= b or b <= a for a, b in pairs)
print("Total order?", all_comparable)          # True
print("Sorted chain:", sorted(S))              # [2, 3, 5]

    Running this cell confirms that every pair in $S$ satisfies comparability and that sorted recovers the unique linear arrangement — a direct computational witness to the definition.
