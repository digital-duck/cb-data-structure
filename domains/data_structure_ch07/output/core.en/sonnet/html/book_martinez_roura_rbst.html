Concept Book: Martinez Roura Rbst

Payoff

The Martínez–Roura randomized binary search tree (RBST) synthesizes two threads that have run through this entire text: the power of randomization to defeat adversarial inputs, and the elegance of structural invariants maintained without auxiliary bookkeeping.

What the RBST achieves. An ordinary BST degrades to $O(n)$ height when keys arrive in sorted order; balanced alternatives such as AVL or red-black trees restore $O(\log n)$ height at the cost of rotations triggered by elaborate case analysis. The RBST of Martínez and Roura (1998) achieves $O(\log n)$ expected height for any insertion sequence by a single probabilistic device: whenever a new key is inserted into a subtree of size $n$, it is promoted to the root of that subtree with probability $\tfrac{1}{n+1}$, and a standard split-and-relink rotation carries it upward. This one rule guarantees that the resulting tree follows exactly the same distribution as a BST built from a uniformly random permutation of its keys—regardless of the order supplied by the caller.

Worked example. Insert keys $3, 5, 7$ in that order. After inserting $3$ the tree is a single node. Inserting $5$ into a size-$1$ tree promotes it to the root with probability $\tfrac{1}{2}$; suppose the coin lands tails, so $5$ becomes the right child of $3$. Inserting $7$ into the right subtree of size $1$ promotes it to the local root with probability $\tfrac{1}{2}$, and a further promotion to the global root requires winning twice (probability $\tfrac{1}{3}$). The resulting shape is drawn from the uniform distribution over all $3! = 6$ BST shapes, exactly as if we had shuffled $\{3,5,7\}$ first.

Key theorem (Martínez–Roura 1998). Let $C_n$ denote the expected number of comparisons for a successful search in an RBST holding $n$ distinct keys. Then

$$C_n \;\leq\; 2H_{n+1} - 1,$$

where $H_n = \sum_{k=1}^{n} \tfrac{1}{k}$ is the $n$-th harmonic number. Since $H_n = \ln n + O(1)$, every dictionary operation—search, insert, delete—executes in $\Theta(\log n)$ expected time with leading constant $\tfrac{2}{\ln 2} \approx 2.885$ comparisons per doubling of $n$.

Lab cell.

from sympy import harmonic, ln, oo, symbols, simplify, limit

n = symbols('n', positive=True, integer=True)

C = 2*harmonic(n + 1) - 1          # theorem's upper bound
ratio = simplify(C / ln(n))
print(limit(ratio, n, oo))          # prints 2, confirming Θ(ln n)

Running this cell confirms the asymptotic ratio is exactly $2$, matching the theorem's guarantee.

The RBST is the natural capstone of this text because it shows that randomization at the structural level—not merely in pivot selection or hash seeds—can replace the elaborate invariant-maintenance machinery of deterministic balanced trees. Every application that demands a mutable ordered dictionary inherits this guarantee with no change to the caller's interface: order-statistics queries augment each node with a subtree size and support rank and select in $O(\log n)$ expected time; interval trees store endpoint pairs and answer stabbing queries by the same probabilistic height bound; geometric sweep-line algorithms use the RBST as a dynamic event queue whose expected cost matches the deterministic lower bound. To explore one of these directions in depth, turn to the next chapter, where we build a randomized order-statistics tree on top of the RBST, supporting one-dimensional range reporting and opening the door to computational geometry.
