Martinez Roura Rbst

Definition. A Martinez–Roura randomized binary search tree (RBST) on $n$ keys is a binary search tree constructed so that, at every node, each of its descendant keys is equally likely to occupy the root. Formally, if $T$ is an RBST storing the ordered set $\{x_1 < x_2 < \cdots < x_n\}$, then for every $i \in \{1, \ldots, n\}$ the probability that $x_i$ is the root equals $\tfrac{1}{n}$. This invariant is maintained recursively in each subtree, so the entire structure follows the same distribution as a BST built by inserting keys in a uniformly random permutation.

Worked Example. Insert the keys $\{3, 1, 4\}$ into an initially empty RBST.

Step 1. The tree is empty. Insert $3$; it becomes the root with probability $\tfrac{1}{1} = 1$.

Step 2. Insert $1$. With probability $\tfrac{1}{2}$ it becomes the new root; with probability $\tfrac{1}{2}$ it descends by ordinary BST comparison. Suppose the second outcome occurs: $1$ becomes the left child of $3$.

Step 3. Insert $4$. With probability $\tfrac{1}{3}$ it becomes the root; with probability $\tfrac{2}{3}$ it recurses into a subtree—here the empty right subtree of $3$, so $4$ becomes the right child of $3$. Across many independent trials, all three possible tree shapes occur with equal frequency, confirming the invariant.

Key Theorem (Martínez & Roura, 1998). Let $T_n$ denote an RBST on $n$ keys. The expected cost of search, insertion, and deletion is $\Theta(\log n)$. More precisely, the expected number of comparisons for a random search satisfies

$$\mathbb{E}[\text{comparisons}] = 2H_n - 1,$$

where $H_n = \sum_{k=1}^{n} \tfrac{1}{k}$ is the $n$-th harmonic number. The proof writes a recurrence for the expected depth of a key conditioned on the random root choice, then solves it using the identity $\sum_{k=1}^{n-1}\tfrac{2}{n} = 2(H_n - 1)$.

Lab Cell (SymPy).

from sympy import symbols, harmonic, latex

n = symbols('n', positive=True, integer=True)
expected_comparisons = 2 * harmonic(n) - 1

print("Expected comparisons:", expected_comparisons)
print("LaTeX:", latex(expected_comparisons))

# Evaluate for small n
for val in [4, 8, 16, 32]:
    print(f"n={val}: E = {float(expected_comparisons.subs(n, val)):.4f}")

Running this cell prints the closed form $2H_n - 1$ and its numerical values, illustrating logarithmic growth: for $n = 32$ the expected comparison count is approximately $6.94$, compared with $\log_2 32 = 5$, confirming the small constant factor that makes RBSTs practical.
