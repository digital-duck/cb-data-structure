Concept Book: Sequence Data Structure

Data Structure Ch08 · Generated by SPL

Payoff

A sequence is among the most fundamental abstractions in mathematics and computer science alike, yet its power is easy to underestimate precisely because it is so ubiquitous. Having built up the machinery of ordered collections, index-based access, concatenation, and slicing, we arrive at a structure that is not merely convenient but inevitable: any process that unfolds in time, any function sampled at discrete points, any word formed from an alphabet—all are sequences. The sequence data structure is the natural endpoint of our study because it unifies discrete and continuous thinking under one roof, bridging the gap between the abstract $n$-tuple of algebra and the dynamic, mutable array of a running program.

What the sequence achieves. Formally, a finite sequence of length $n$ over a set $S$ is a function $a : \{0, 1, \dots, n-1\} \to S$, written $(a_0, a_1, \dots, a_{n-1})$. This deceptively simple definition carries three guarantees that no unordered structure can provide: (1) positional identity—element $a_i$ is uniquely determined by its index $i$; (2) order preservation—the relative arrangement of elements is intrinsic to the object itself; and (3) composability—two sequences $(a_0, \dots, a_{m-1})$ and $(b_0, \dots, b_{n-1})$ concatenate to a new sequence of length $m + n$, and every subsequence $a_{i:j}$ is itself a well-formed sequence, closed under the same operations.

Worked example. Consider the Fibonacci sequence defined by $F_0 = 0$, $F_1 = 1$, and $F_n = F_{n-1} + F_{n-2}$ for $n \geq 2$. Treating $(F_0, F_1, F_2, \dots)$ as an infinite sequence over $\mathbb{N}$, the ratio of consecutive terms converges:

$$\lim_{n \to \infty} \frac{F_{n+1}}{F_n} = \varphi = \frac{1 + \sqrt{5}}{2}.$$

This single identity—derivable by assuming the limit $L$ exists and solving $L = 1 + 1/L$—illustrates how the sequence structure lets us reason about dynamic processes (the recurrence) and static limits (the golden ratio) within the same framework.

Key theorem. (Bolzano–Weierstrass, discrete analogue.) Every bounded infinite sequence of real numbers contains a monotone subsequence. Equivalently, if $|a_i| \leq M$ for all $i$, there exists an index set $i_0 < i_1 < i_2 < \cdots$ such that $(a_{i_k})_{k \geq 0}$ is non-decreasing or non-increasing. This theorem guarantees that sequences, however erratic, always harbor hidden regularity—a fact exploited in sorting algorithms, signal processing, and numerical analysis alike.

Lab cell.

from sympy import symbols, Function, rsolve, sqrt, Rational

n = symbols('n', integer=True, nonneg=True)
F = Function('F')

# Solve the Fibonacci recurrence symbolically
sol = rsolve(F(n) - F(n-1) - F(n-2), F(n), {F(0): 0, F(1): 1})
print("Closed form:", sol)          # Binet's formula

# Verify the golden-ratio limit numerically
phi = (1 + sqrt(5)) / 2
fibs = [0, 1]
for _ in range(18):
    fibs.append(fibs[-1] + fibs[-2])
ratios = [Rational(fibs[k+1], fibs[k]) for k in range(1, 19)]
print("Successive ratios:", [float(r) for r in ratios[-5:]])
print("Golden ratio φ ≈", float(phi))

Every topic that follows in this text, from matrix algorithms that process rows as sequences of scalars, to parsing algorithms that consume tokens one position at a time, to the discrete Fourier transform that decomposes a sampled signal into frequency components, rests on the ordered, indexed collection you have just mastered.
