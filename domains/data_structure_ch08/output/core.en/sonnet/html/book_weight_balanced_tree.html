Concept Book: Weight Balanced Tree

Data Structure Ch08 · Generated by SPL

Payoff

A weight-balanced tree (also called a BB[$\alpha$]-tree) is a binary search tree in which every node $v$ satisfies the balance invariant

$$\alpha \;\le\; \frac{|T_\ell(v)|}{|T(v)|} \;\le\; 1 - \alpha,$$

where $|T(v)|$ denotes the number of nodes in the subtree rooted at $v$, $T_\ell(v)$ is its left subtree, and $\alpha \in \bigl(0, \tfrac{1}{2}\bigr]$ is a fixed balance parameter, typically chosen near $\tfrac{2}{9}$ for optimal rotation counts. Unlike height-balanced trees, whose invariants are stated in terms of depth, this criterion measures mass: each subtree must hold a guaranteed fraction of its parent's population. Because node count is a concrete integer, the invariant is trivially checkable in $O(1)$ time given cached subtree sizes.

Worked example. Insert the sequence $1, 2, 3, 4, 5$ with $\alpha = \tfrac{29}{100}$.

After inserting $3$ as root, $4$, then $5$, the right subtree holds $2$ nodes while the total is $3$, giving right-weight ratio $\tfrac{2}{3} \approx 0.667 > 1 - 0.29 = 0.71$—a violation. A single left rotation at the root restores balance, producing root $4$ with left child $3$ (holding node $1$ and $2$) and right child $5$. Verify: $|T_\ell(4)| = 3$, $|T(4)| = 5$, ratio $= 0.6$, which lies in $[0.29,\, 0.71]$. Every node now satisfies the invariant.

Theorem (logarithmic height). For any BB[$\alpha$]-tree on $n$ nodes, the height $h$ satisfies

$$h \;\le\; \log_{1/(1-\alpha)} n.$$

Proof sketch. The invariant forces the heavier subtree to contain at most $(1-\alpha)$ fraction of the parent's nodes. Descending any root-to-leaf path, the subtree size shrinks by at least a factor of $(1-\alpha)$ at every step. After $h$ steps the size is at most $n(1-\alpha)^h \ge 1$, yielding $h \le \log_{1/(1-\alpha)} n$. $\square$

This bound makes the weight-balanced tree the natural endpoint of the chapter's progression: every structural property developed earlier—rotation, size augmentation, recursive decomposition—converges here into a single clean ratio that simultaneously enforces balance, supports order-statistic queries in $O(\log n)$, and admits worst-case $O(\log n)$ insertion and deletion with a small constant number of rotations.

Lab cell.

from sympy import log, Rational, simplify

alpha = Rational(29, 100)
n     = 1000
h_bound = log(n) / log(1 / (1 - alpha))
print("Height bound for n =", n, ":", simplify(h_bound).evalf(4))
# Expected: ≈ 14.9  (compare to ⌊log₂ 1000⌋ = 9 for perfect binary tree)

Running this cell makes the cost of choosing a loose $\alpha$ tangible: a smaller balance parameter keeps the tree more permissive but allows taller paths.
