Dynamite Tree

Definition. Let $T = (V, E)$ be a tree with $n$ vertices. For a non-negative integer $r$, an $r$-dominating set of $T$ is a subset $S \subseteq V$ such that for every vertex $v \in V$ there exists some $s \in S$ with $d_T(v, s) \leq r$, where $d_T$ denotes the unique-path distance in $T$. The dynamite tree problem asks: given $T$ and a charge budget $k \in \mathbb{Z}^+$, find the minimum blast radius

$$r^* = \min\bigl\{r \geq 0 : T \text{ admits an } r\text{-dominating set of size} \leq k\bigr\}.$$

Each element of $S$ is called a charge; the imagery is that detonating $k$ charges, each destroying every vertex within distance $r$, must collectively cover the entire tree.

Worked example. Consider the path $P_7$ with vertices $v_0, v_1, \ldots, v_6$ and edges $\{v_i, v_{i+1}\}$. With budget $k = 2$ and trial radius $r = 1$, placing charges at $v_1$ and $v_5$ covers $\{v_0, v_1, v_2\}$ and $\{v_4, v_5, v_6\}$, leaving $v_3$ uncovered. No two-charge placement achieves $r = 1$. At $r = 2$, placing charges at $v_2$ and $v_4$ covers $\{v_0,\ldots,v_4\}$ and $\{v_2,\ldots,v_6\}$ respectively, so every vertex is reached. Hence $r^* = 2$.

Key theorem (Greedy optimality). For fixed $r$, the minimum number of charges required to $r$-dominate $T$ is computable in $O(n)$ time by the following greedy: process vertices in reverse DFS order (leaves first); whenever an uncovered leaf $\ell$ is encountered, place a charge at the ancestor of $\ell$ exactly $\min(r, \text{depth}(\ell))$ edges above $\ell$, then mark all vertices within distance $r$ of that ancestor as covered.

Proof sketch. Every leaf must be covered. Placing the charge as high above $\ell$ as $\ell$'s coverage constraint allows maximises subtree coverage. A standard exchange argument shows that any optimal solution can be transformed, one charge at a time, to agree with the greedy placement without increasing the charge count, establishing optimality.

Combining this greedy with binary search over $r \in \{0, 1, \ldots, n-1\}$ yields an $O(n \log n)$ algorithm for the full dynamite tree problem.

Lab cell.

import networkx as nx

def greedy_charges(tree: nx.Graph, root: int, r: int) -> int:
    order = list(nx.dfs_preorder_nodes(tree, root))
    covered = set()
    count = 0
    for v in reversed(order):
        if v not in covered:
            path = nx.shortest_path(tree, root, v)
            charge = path[max(0, len(path) - 1 - r)]
            count += 1
            covered |= {u for u in tree
                        if nx.shortest_path_length(tree, charge, u) <= r}
    return count

P7 = nx.path_graph(7)
print(greedy_charges(P7, root=0, r=2))   # → 2
print(greedy_charges(P7, root=0, r=1))   # → 3

Experiment by substituting a star graph $K_{1,m}$ or a balanced binary tree to observe how $r^*$ grows with $k$ and tree diameter.
