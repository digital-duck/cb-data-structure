Scapegoat Add

Definition. A scapegoat tree is a binary search tree (BST) that maintains approximate balance by selectively rebuilding subtrees upon insertion. Unlike AVL or red–black trees, it requires no per-node balance metadata; instead, it uses a global weight parameter $\alpha \in \bigl(\tfrac{1}{2}, 1\bigr)$ to define the $\alpha$-weight-balance property. A node $v$ with subtree size $\mathrm{size}(v)$ is called $\alpha$-balanced if

$$\mathrm{size}(\mathrm{left}(v)) \leq \alpha \cdot \mathrm{size}(v) \quad \text{and} \quad \mathrm{size}(\mathrm{right}(v)) \leq \alpha \cdot \mathrm{size}(v).$$

The scapegoat add operation inserts a key $k$ into the tree via standard BST insertion, then walks back up the insertion path to find the highest ancestor that violates $\alpha$-weight-balance. That ancestor is the scapegoat node; its entire subtree is flattened into a sorted array and rebuilt as a perfectly balanced BST in $O(m)$ time, where $m$ is the size of the scapegoat's subtree.

Worked Example. Let $\alpha = 0.6$ and suppose the tree contains keys $\{10, 20, 30, 40, 50\}$ arranged so that the root (key $30$) has a left subtree of size $1$ and a right subtree of size $3$. Before inserting $k = 45$:

$$\mathrm{size}(\mathrm{right}(\text{root})) = 3, \quad \mathrm{size}(\text{root}) = 5.$$

After inserting $45$ into the right subtree, the right child grows to size $4$, giving $\mathrm{size}(\mathrm{right}(\text{root})) / \mathrm{size}(\text{root}) = 4/6 \approx 0.667 > 0.6$. The root is identified as the scapegoat. The subtree $\{10, 20, 30, 40, 45, 50\}$ is collected in order and rebuilt with $40$ as the new root, restoring $\alpha$-balance.

Key Theorem (Amortized Cost). For a scapegoat tree with parameter $\alpha$, a sequence of $n$ insertions has a total cost of $O(n \log n)$, giving an amortized cost of $O(\log n)$ per insertion. The proof uses a potential function $\Phi = c \sum_{v} |\mathrm{size}(\mathrm{left}(v)) - \mathrm{size}(\mathrm{right}(v))|$; each rebuild reduces $\Phi$ enough to pay for the $O(m)$ reconstruction work.

Lab Cell (SymPy).

from sympy import Integer, floor, log

alpha = Integer(6) / 10   # α = 0.6
n = 20                    # number of insertions

# Theoretical height bound: log_{1/alpha}(n)
height_bound = log(n, 1 / alpha)
print(f"Alpha: {float(alpha):.2f}")
print(f"Height bound for n={n}: {float(height_bound):.3f}")
# Verify: rebuild triggered when size(child) > alpha * size(parent)
for m in range(1, n + 1):
    threshold = floor(alpha * m)
    print(f"  size={m}, max child size allowed = {threshold}")
