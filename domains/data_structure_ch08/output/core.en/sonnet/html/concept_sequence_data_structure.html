Sequence Data Structure

Definition. A sequence is an ordered collection of elements in which each element occupies a uniquely indexed position. Formally, a finite sequence of length $n$ over a set $S$ is a function

$$a : \{0, 1, 2, \ldots, n-1\} \longrightarrow S, \quad i \mapsto a_i,$$

denoted $(a_0, a_1, \ldots, a_{n-1})$. Order and multiplicity both matter: $(1, 2, 2, 3) \neq (1, 2, 3)$ and $(1, 2, 3) \neq (3, 2, 1)$. An infinite sequence extends the domain to $\mathbb{N}$, written $(a_n)_{n \geq 0}$.

Worked Example. Consider the arithmetic sequence defined by $a_n = 3n + 1$ for $n \geq 0$. The first five terms are obtained by substitution:

$$a_0 = 1,\quad a_1 = 4,\quad a_2 = 7,\quad a_3 = 10,\quad a_4 = 13.$$

The common difference is $d = a_{n+1} - a_n = 3$ for all $n$. The partial sum of the first $N$ terms is

$$S_N = \sum_{n=0}^{N-1} a_n = \sum_{n=0}^{N-1}(3n+1) = \frac{3N(N-1)}{2} + N = \frac{N(3N-1)}{2}.$$

For $N = 5$, this gives $S_5 = \frac{5 \cdot 14}{2} = 35$, which can be verified directly: $1+4+7+10+13 = 35$.

Key Theorem (Arithmetic Partial Sum). Let $(a_n)$ be an arithmetic sequence with first term $a_0$ and common difference $d$. Then

$$S_N = \frac{N}{2}\bigl(2a_0 + (N-1)d\bigr).$$

Proof sketch. Write $S_N$ forwards and backwards simultaneously:

$$S_N = a_0 + (a_0+d) + \cdots + (a_0+(N-1)d),$$ $$S_N = (a_0+(N-1)d) + \cdots + a_0.$$

Adding term-by-term yields $2S_N = N(2a_0 + (N-1)d)$, and division by 2 gives the result. $\square$

Lab Cell.

from sympy import symbols, summation, simplify, factor

n, N = symbols('n N', integer=True, nonneg=True)
a_n = 3*n + 1
partial_sum = summation(a_n, (n, 0, N - 1))
print("Partial sum:", factor(simplify(partial_sum)))   # N*(3*N - 1)/2

# Verify numerically for N=5
print("S_5 =", partial_sum.subs(N, 5))                # 35

Running this cell confirms both the symbolic formula and the numerical check, illustrating how SymPy can verify closed-form summation identities derived analytically.
