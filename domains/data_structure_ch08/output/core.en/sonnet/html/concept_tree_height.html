Tree Height

Definition. Let $T$ be a rooted tree with root $r$. The height of a node $v$, written $h(v)$, is the length of the longest path (measured in edges) from $v$ to any leaf in the subtree rooted at $v$. The height of the tree, written $h(T)$, is defined as the height of the root:

$$h(T) = h(r) = \max_{v \in \text{leaves}(T)} d(r, v),$$

where $d(r, v)$ denotes the number of edges on the unique path from $r$ to leaf $v$. Leaves themselves have height $0$. An empty tree is assigned height $-1$ by convention, which simplifies recursive formulae.

Recursive characterisation. For any internal node $v$ with children $c_1, c_2, \ldots, c_k$,

$$h(v) = 1 + \max_{1 \le i \le k} h(c_i).$$

This recurrence is the computational foundation of every tree-height algorithm.

Worked example. Consider the binary tree whose edges are $\{(A,B),(A,C),(B,D),(B,E),(C,F)\}$ with root $A$. Applying the recurrence bottom-up: $h(D)=h(E)=h(F)=0$; $h(B)=1+\max(0,0)=1$; $h(C)=1+\max(0)=1$; $h(A)=1+\max(1,1)=2$. Thus $h(T)=2$, confirmed by the path $A\to B\to D$ (or $A\to B\to E$), each containing exactly two edges.

Theorem (height–node bound). A binary tree with $n$ nodes satisfies

$$\lfloor \log_2 n \rfloor \le h(T) \le n-1.$$

The lower bound is achieved by a complete binary tree (levels filled left to right), where $n \approx 2^{h+1}$. The upper bound is achieved by a path graph (each node has exactly one child), which degenerates to a linked list.

Proof sketch. A complete binary tree of height $h$ contains at most $2^{h+1}-1$ nodes, giving $h \ge \log_2(n+1)-1 > \lfloor \log_2 n\rfloor - 1$, hence the lower bound. A path of $n$ nodes has $n-1$ edges from root to leaf, giving the upper bound. $\square$

from sympy import symbols, Function, Max, Integer
from sympy.combinatorics import *

def tree_height(adj, root):
    """Return height of rooted tree given as adjacency dict {node: [children]}."""
    children = adj.get(root, [])
    if not children:
        return 0
    return 1 + max(tree_height(adj, c) for c in children)

adj = {'A': ['B', 'C'], 'B': ['D', 'E'], 'C': ['F'], 'D': [], 'E': [], 'F': []}
print(tree_height(adj, 'A'))  # Expected: 2
