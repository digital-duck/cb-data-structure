红黑树的插入(Red Black Add)

定义

在左倾红黑树(LLRB)中,每个结点的链接要么是红色,要么是黑色。红链接把一个结点与其父结点"粘合"在一起,对应 2-4 树中的一个多键结点。LLRB 需要满足三条性质:

  • 左倾:红链接只能是左链接;
  • 无连续红边:不存在两条相连的红链接;
  • 完美黑平衡:从根到任意空链接的路径上,黑链接数目相同。

    • 插入(add) 分两步:先按普通二叉搜索树(BST)的规则找到空位,把新键作为红色叶结点挂上去;再沿插入路径回溯,用 add_fixup 恢复上述性质。新结点取红色,是因为它相当于把一个键并入 2-4 树中已有的结点,不会改变黑高度。

    add_fixup 的三条规则

    回溯时,对每个结点 $h$ 依次检查:

    def add_fixup(h):
    if is_red(h.right) and not is_red(h.left):   # 右倾红边
        h = rotate_left(h)
    if is_red(h.left) and is_red(h.left.left):   # 连续两条红边
        h = rotate_right(h)
    if is_red(h.left) and is_red(h.right):       # 4-结点
        flip_colors(h)                           # 分裂
    return h
  • 左旋:修正右倾红链接,使 3-结点符合左倾约定;
  • 右旋:把"左-左"连续红链接变成一个中间结点带两条红链接的临时 4-结点;
  • 颜色翻转:把两个子结点变黑、$h$ 变红,相当于 2-4 树中把 4-结点分裂,并将中间键上推给父结点。

    • 例题

    依次向空树插入 $10, 20, 30$。

  • 插入 $10$:根结点。根必须是黑色。
  • 插入 $20$:作为 $10$ 的右红子结点,出现右倾红边,左旋后 $20$ 为根,$10$ 为其红色左子。
  • 插入 $30$:作为 $20$ 的右红子。此时 $20$ 的左、右子结点均为红,形成 4-结点 $[10,20,30]$,执行颜色翻转:$10$、$30$ 变黑,$20$ 变红;再把根重新染黑。

    • 结果是一棵高度为 2 的平衡树,黑高度为 2。

    问题求解应用

    问题:依次插入 $10,20,30,40$,说明最后一步会触发什么操作。

    解:前三步得到根 $20$(黑),左右子 $10$、$30$ 均为黑。插入 $40$ 作为 $30$ 的红色右子,右倾红边,add_fixup 在 $30$ 处执行左旋,得到 $40$(黑)的红色左子 $30$。回溯到 $20$:左右子均不是红,无需处理。此时 $20$ 的右子 $40$ 与其左子 $30$ 构成 3-结点 $[30,40]$。

    复杂度:LLRB 的高度不超过 $2\log_2 N$(对应 2-4 树高度 $\le \log_2 N$,每层最多多出一条红链接)。插入沿一条路径下行再回溯,每个结点最多做常数次旋转与翻转,因此

    $$T_{\text{add}}(N)=O(\log N).$$
