Concept Book: Avl Tree

Data Structure Ch09 · Generated by SPL

Payoff

An AVL tree is a self-balancing binary search tree in which, for every node $v$, the heights of its left and right subtrees differ by at most one. Formally, define the balance factor of a node as

$$\beta(v) = h(\text{left}(v)) - h(\text{right}(v)),$$

where $h(\cdot)$ denotes subtree height and $h(\varnothing) = -1$ by convention. A binary search tree is an AVL tree if and only if $\beta(v) \in \{-1, 0, 1\}$ for every node $v$.

This single invariant is the capstone because it synthesises every idea developed in the preceding chapters: the ordering property of binary search trees, the recursive height measure, rotation as a structure-preserving transformation, and inductive proof over tree shape. Maintaining $|\beta(v)| \leq 1$ after every insertion or deletion requires at most $O(\log n)$ rotations, and it guarantees that the tree height never exceeds $1.44 \log_2(n+2)$, making search, insertion, and deletion each run in worst-case $\Theta(\log n)$ time — a bound that a plain binary search tree cannot promise.

Worked example. Insert the keys $3, 2, 1$ into an empty AVL tree. After inserting $3$ and $2$ the tree is balanced. Inserting $1$ gives the left-left case: node $3$ acquires $\beta(3) = 2$. A single right rotation at $3$ produces the balanced tree with $2$ as root, $1$ as left child, and $3$ as right child. All three balance factors become $0$.

Theorem (AVL height bound). An AVL tree storing $n$ keys has height $h \leq \lfloor 1.44 \log_2(n+2) \rfloor - 1$. The proof proceeds by constructing the Fibonacci trees $T_k$, the AVL trees of height $k$ with the fewest nodes, and showing $|T_k| = F_{k+3} - 1$, where $F_k$ is the $k$-th Fibonacci number. Since $F_k \sim \phi^k / \sqrt{5}$ with $\phi \approx 1.618$, inverting gives the logarithmic height bound.

from sympy import symbols, Integer, log, floor, N

n = symbols('n', positive=True, integer=True)
h_bound = floor(Integer(144) * log(n + 2, 10) / Integer(100))

# Verify for n = 1000
print(f"Height bound for n=1000: {h_bound.subs(n, 1000)}")  # ≤ 13

The AVL tree is not merely the end of a chapter — it is the beginning of a larger conversation. Every modern database index, every in-memory ordered map, and every interval-scheduling algorithm stands on the guarantee that height remains logarithmic. Having internalised rotations and the balance invariant, you are now equipped to explore red-black trees (which relax the invariant for cheaper rebalancing), B-trees (which generalise branching for disk-resident data), and augmented BSTs (which attach satellite information to each node to answer range, order-statistic, and interval queries in $O(\log n)$). Choose one of these directions and carry the invariant-rotation framework with you: the same two ideas that tamed height here will tame every structure you encounter next.
