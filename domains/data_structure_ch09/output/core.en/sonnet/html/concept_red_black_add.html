Red Black Add

Definition. A red-black tree is a binary search tree in which every node carries a colour attribute, either red or black, satisfying the following invariants:

  • Every node is red or black.
  • The root is black.
  • Every null leaf (sentinel) is black.
  • A red node has no red children (no double-red).
  • Every simple path from a node to any descendant null leaf contains the same number of black nodes (black-height uniformity).

    • The operation red\_black\_add inserts a key $k$ into such a tree while restoring all five invariants. The algorithm proceeds in two phases. Phase 1 performs an ordinary BST insertion, colouring the new node red to preserve black-height. Phase 2 applies a sequence of local fix-up rotations and recolourings to eliminate any double-red violation introduced by Phase 1.

    Worked Example. Consider inserting $k = 4$ into the tree with root $10$ (black), left child $5$ (black), and $5$'s left child $2$ (red). Standard BST insertion places $4$ as the right child of $2$, coloured red. Now $2$ (red) has a red child $4$, violating Invariant 4. The fix-up procedure inspects $4$'s uncle, which is the null sentinel (black). This triggers a right rotation at $5$ followed by a left rotation at $10$, then a recolouring: $5$ becomes black and its two children $2$ and $10$ become red. All five invariants hold in the resulting tree.

    Key Theorem (Logarithmic Height). A red-black tree storing $n$ keys has height at most $2\log_2(n+1)$. Because at least half of any root-to-leaf path must be black (Invariant 4) and all such paths have equal black-height $h_b$ (Invariant 5), the total height satisfies $h \leq 2h_b \leq 2\log_2(n+1)$. Consequently, red\_black\_add runs in $O(\log n)$ time in the worst case, performing at most $O(\log n)$ fix-up steps with at most two rotations total.

    Lab Cell (SymPy/Python).

    from sympy import symbols, log, simplify

n = symbols('n', positive=True)
height_bound = 2 * log(n + 1, 2)
print("Height bound:", simplify(height_bound))

# Verify bound for small n
for val in [1, 7, 15, 31]:
    print(f"n={val}: bound = {float(height_bound.subs(n, val)):.2f}")

    Running this cell confirms that for $n = 15$ nodes the height is bounded by $8$, matching the four-level complete binary tree that achieves exactly $2\log_2 16 = 8$.
