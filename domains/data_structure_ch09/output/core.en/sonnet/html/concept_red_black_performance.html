Red Black Performance

Definition. A red-black tree is a self-balancing binary search tree in which every node carries a colour bit (red or black) subject to four invariants: (1) the root is black; (2) every leaf (NIL sentinel) is black; (3) both children of every red node are black; (4) every simple path from a given node to any descendant leaf contains the same number of black nodes, called the black-height $bh(x)$ of node $x$. These invariants together bound the height of an $n$-node tree.

Key Theorem (Height Bound). For a red-black tree with $n$ internal nodes, the height $h$ satisfies

$$h \leq 2\log_2(n+1).$$

Proof sketch. By invariant (4), every subtree rooted at $x$ contains at least $2^{bh(x)}-1$ internal nodes. Since invariant (3) prevents two consecutive red nodes, at least half of the nodes on any root-to-leaf path are black, giving $bh(\text{root}) \geq h/2$. Combining: $n \geq 2^{h/2}-1$, so $h \leq 2\log_2(n+1)$. $\square$

Because search, insertion, and deletion each traverse at most one root-to-leaf path, all three operations run in $O(\log n)$ worst-case time—unlike an ordinary BST, which degrades to $O(n)$ on sorted input.

Worked Example. Insert the keys $\{10, 20, 30\}$ into an empty red-black tree. After inserting 10 (root → coloured black), insert 20 as a red right child of 10—no violation. Insert 30 as a red right child of 20: this creates two consecutive red nodes (violation of invariant 3). A single left rotation at node 10 and a colour swap yield 20 as the new black root with red children 10 and 30. The black-height is 1 throughout; $h = 2 \leq 2\log_2(4) = 4$. ✓

Lab Cell (SymPy).

from sympy import log, floor, simplify, symbols

n = symbols('n', positive=True, integer=True)
height_bound = 2 * log(n + 1, 2)

# Verify the bound for n = 1000
n_val = 1000
bound = float(height_bound.subs(n, n_val))
print(f"n = {n_val}: height ≤ {bound:.2f}")   # ≤ 19.93

# Compare with a worst-case linear BST
print(f"Unbalanced BST worst case: {n_val}")

Running this cell confirms that a red-black tree with 1 000 nodes guarantees search in at most 20 comparisons, while a degenerate BST may require 1 000—a factor-of-50 improvement that illustrates why balanced trees underpin every production-grade ordered data structure.
