Absorb Operation

Definition. Let $(L, \leq)$ be a lattice with meet $\wedge$ and join $\vee$. The absorb operation refers to the pair of binary identities

$$a \vee (a \wedge b) = a \qquad \text{and} \qquad a \wedge (a \vee b) = a,$$

which hold for all $a, b \in L$. These are called the absorption laws. Informally, the larger (or dominating) operand absorbs the expression involving both elements, collapsing it back to itself. Absorption is not a single function but rather a structural property that every lattice satisfies, and it encodes the consistency between the two lattice operations.

Worked Example. Consider the power-set lattice $(\mathcal{P}(\{1,2,3\}), \subseteq)$, where $\wedge = \cap$ and $\vee = \cup$. Take $a = \{1,2\}$ and $b = \{2,3\}$.

  • First law: $a \cup (a \cap b) = \{1,2\} \cup (\{1,2\} \cap \{2,3\}) = \{1,2\} \cup \{2\} = \{1,2\} = a$. $\checkmark$
  • Second law: $a \cap (a \cup b) = \{1,2\} \cap (\{1,2\} \cup \{2,3\}) = \{1,2\} \cap \{1,2,3\} = \{1,2\} = a$. $\checkmark$

    • In both cases the result is simply $a$, demonstrating that inclusion relationships between $a$ and the compound expression cause one operand to dominate.

    Key Theorem (Absorption Characterizes Lattices). A set $L$ equipped with two binary operations $\wedge$ and $\vee$ is a lattice if and only if both operations are commutative, associative, idempotent ($a \wedge a = a$, $a \vee a = a$), and satisfy the absorption laws. In particular, absorption is not derivable from commutativity and associativity alone; it is the axiom that ties meet and join into a coherent order structure. The partial order can then be recovered by defining $a \leq b \iff a \wedge b = a$.

    Lab Cell (SymPy).

    from sympy import symbols, And, Or, simplify_logic

a, b = symbols('a b')

# Absorption: a | (a & b) == a
expr1 = Or(a, And(a, b))
print(simplify_logic(expr1))          # Expected: a

# Absorption: a & (a | b) == a
expr2 = And(a, Or(a, b))
print(simplify_logic(expr2))          # Expected: a

    Running these cells confirms that SymPy's Boolean simplifier reduces both absorbed expressions to the absorbing element $a$, mirroring the algebraic proof.
