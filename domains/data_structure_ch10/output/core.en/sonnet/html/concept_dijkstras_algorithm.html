Dijkstras Algorithm

Definition. Let $G = (V, E, w)$ be a weighted directed graph where $V$ is the vertex set, $E \subseteq V \times V$ is the edge set, and $w : E \to \mathbb{R}_{\geq 0}$ assigns a non-negative weight to each edge. Given a source vertex $s \in V$, Dijkstra's algorithm computes, for every vertex $v \in V$, the length of a shortest path $\delta(s, v) = \min\{\sum_{e \in P} w(e) : P \text{ is a path from } s \text{ to } v\}$. The algorithm maintains a tentative distance $d[v]$ for each vertex, initialised to $d[s] = 0$ and $d[v] = \infty$ for $v \neq s$, and iteratively relaxes edges by updating $d[v] \leftarrow \min(d[v],\, d[u] + w(u,v))$ for each neighbour $v$ of the vertex $u$ currently extracted from a min-priority queue.

Worked Example. Consider the graph with vertices $\{A, B, C, D\}$ and weighted edges $A \to B$ (1), $A \to C$ (4), $B \to C$ (2), $B \to D$ (6), $C \to D$ (3). Source $s = A$.

| Step | Extracted | $d[A]$ | $d[B]$ | $d[C]$ | $d[D]$ | |------|-----------|--------|--------|--------|--------| | 0 | — | 0 | $\infty$ | $\infty$ | $\infty$ | | 1 | $A$ | 0 | 1 | 4 | $\infty$ | | 2 | $B$ | 0 | 1 | 3 | 7 | | 3 | $C$ | 0 | 1 | 3 | 6 | | 4 | $D$ | 0 | 1 | 3 | 6 |

The shortest distances from $A$ are therefore $\delta(A,B)=1$, $\delta(A,C)=3$, $\delta(A,D)=6$.

Theorem (Correctness and Complexity). When all edge weights are non-negative, Dijkstra's algorithm correctly computes $\delta(s,v)$ for all $v \in V$. The key invariant is that once a vertex $u$ is extracted from the priority queue, $d[u] = \delta(s,u)$; non-negativity prevents any future path from improving upon this value. With a binary min-heap, the algorithm runs in $O((|V| + |E|)\log |V|)$ time; a Fibonacci heap reduces this to $O(|E| + |V|\log |V|)$.

import heapq
import sympy as sp

def dijkstra(graph, source):
    dist = {v: sp.oo for v in graph}
    dist[source] = 0
    pq = [(0, source)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, w in graph[u]:
            alt = dist[u] + w
            if alt < dist[v]:
                dist[v] = alt
                heapq.heappush(pq, (alt, v))
    return dist

G = {'A': [('B',1),('C',4)], 'B': [('C',2),('D',6)],
     'C': [('D',3)], 'D': []}
print(dijkstra(G, 'A'))
