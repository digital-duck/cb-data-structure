Heapsort

Definition. A binary max-heap is a complete binary tree stored in an array $A[1\ldots n]$ satisfying the heap property: for every node $i > 1$, $A[\lfloor i/2 \rfloor] \geq A[i]$. Heapsort is a comparison-based sorting algorithm that operates in two phases. First, it transforms the input array into a max-heap in $O(n)$ time via repeated calls to $\textsc{Heapify}$. Second, it repeatedly extracts the maximum element—always located at $A[1]$—swaps it to the end of the unsorted portion, and restores the heap property, sorting the array in place in $O(n \log n)$ time with $O(1)$ auxiliary space.

The $\textsc{Heapify}(A, i, n)$ subroutine assumes both subtrees rooted at $2i$ and $2i+1$ are valid heaps and "sifts down" $A[i]$ by repeatedly swapping it with its larger child until the heap property is restored. Building the heap applies $\textsc{Heapify}$ to every internal node from $\lfloor n/2 \rfloor$ down to $1$.

Worked Example. Sort $A = [3, 1, 4, 1, 5]$.

Build-heap phase: Start at $i = 2$. Node $A[2] = 1$ has children $A[4]=1, A[5]=5$; swap to get $[3,5,4,1,1]$. Then $i=1$: $A[1]=3$ has children $5$ and $4$; swap with $5$ to get $[5,3,4,1,1]$. The max-heap is now valid.

Sort phase: Swap $A[1] \leftrightarrow A[5]$: $[1,3,4,1 \mid 5]$. Heapify on heap of size 4 yields $[4,3,1,1 \mid 5]$. Swap $A[1] \leftrightarrow A[4]$: $[1,3,1 \mid 4,5]$. Continue until the array reads $[1,1,3,4,5]$.

Theorem (Complexity of Heapsort). For an input of size $n$, heapsort performs at most $2n\log_2 n + O(n)$ comparisons and runs in $\Theta(n \log n)$ worst-case time. The build-heap phase costs $O(n)$ because $\sum_{h=0}^{\lfloor \log n \rfloor} \lceil n/2^{h+1} \rceil \cdot O(h) = O(n)$. Each of the $n-1$ extraction steps calls $\textsc{Heapify}$, costing $O(\log n)$ per call, contributing $O(n \log n)$ total.

import sympy as sp

def heapify(A, n, i):
    largest, left, right = i, 2*i + 1, 2*i + 2
    if left < n and A[left] > A[largest]:
        largest = left
    if right < n and A[right] > A[largest]:
        largest = right
    if largest != i:
        A[i], A[largest] = A[largest], A[i]
        heapify(A, n, largest)

def heapsort(A):
    n = len(A)
    for i in range(n // 2 - 1, -1, -1):
        heapify(A, n, i)
    for i in range(n - 1, 0, -1):
        A[0], A[i] = A[i], A[0]
        heapify(A, n, 0)
    return A

data = [3, 1, 4, 1, 5, 9, 2, 6]
sp.pprint(heapsort(data))   # Expected: [1, 1, 2, 3, 4, 5, 6, 9]
