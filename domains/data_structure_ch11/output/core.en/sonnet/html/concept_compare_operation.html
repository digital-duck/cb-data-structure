Compare Operation

Definition. A compare operation on a set $S$ is a binary function $\mathrm{cmp}: S \times S \to \{-1, 0, 1\}$ (or equivalently a mapping into an ordered set of signals) that determines the relative ordering of two elements. Formally, for $a, b \in S$ equipped with a total order $\leq$,

$$ \mathrm{cmp}(a, b) = \begin{cases} -1 & \text{if } a < b, \\ \phantom{-}0 & \text{if } a = b, \\ \phantom{-}1 & \text{if } a > b. \end{cases} $$

The compare operation is the computational primitive underlying sorting, binary search, and decision-tree evaluation. It requires that $\leq$ be a total order: reflexive ($a \leq a$), antisymmetric ($a \leq b \wedge b \leq a \Rightarrow a = b$), transitive ($a \leq b \wedge b \leq c \Rightarrow a \leq c$), and total ($a \leq b$ or $b \leq a$ for all $a, b$).

Worked Example. Let $S = \mathbb{R}$ and consider $a = 3.7$, $b = 5.2$. Computing $\mathrm{cmp}(3.7,\, 5.2)$: since $3.7 < 5.2$, the result is $-1$. Now consider $a = \pi$, $b = \pi$. Because $a = b$, the result is $0$. Finally, $\mathrm{cmp}(7, 2) = 1$ since $7 > 2$. Notice that $\mathrm{cmp}(a, b) = -\,\mathrm{cmp}(b, a)$ in all three cases, illustrating antisymmetry.

Key Theorem (Comparison Lower Bound). Any comparison-based sorting algorithm on $n$ elements requires at least $\lceil \log_2(n!) \rceil$ comparisons in the worst case. By Stirling's approximation, $\log_2(n!) \approx n\log_2 n - n\log_2 e$, so the lower bound is $\Omega(n \log n)$. This follows because each compare operation partitions the remaining permutation space into at most two halves, and the algorithm must distinguish among $n!$ possible orderings; a binary decision tree of depth $d$ has at most $2^d$ leaves, so $2^d \geq n!$ gives $d \geq \log_2(n!)$.

Lab Cell (SymPy).

from sympy import symbols, Piecewise, pi, N

a, b = symbols('a b', real=True)

def cmp(x, y):
    xv, yv = float(N(x)), float(N(y))
    return -1 if xv < yv else (0 if xv == yv else 1)

pairs = [(3.7, 5.2), (pi, pi), (7, 2)]
for x, y in pairs:
    print(f"cmp({x}, {y}) = {cmp(x, y)}")

Running this cell prints cmp(3.7, 5.2) = -1, cmp(π, π) = 0, and cmp(7, 2) = 1, confirming the definition. Students should verify that swapping the arguments negates every result, and explore how cmp generalizes to lexicographic order on tuples by applying it coordinate-wise.
