Non Comparison Sorting

Definition. A non-comparison sorting algorithm is a sorting procedure that determines the output order of elements without performing pairwise comparisons between keys. Instead, such algorithms exploit structural properties of the keys themselves — typically that the keys are integers (or strings) drawn from a bounded domain — to achieve sub-linearithmic time complexity in many practical settings.

The fundamental lower bound for comparison-based sorting states that any deterministic comparison sort requires $\Omega(n \log n)$ comparisons in the worst case, because the decision tree of all possible orderings of $n$ elements has $n!$ leaves and therefore height at least $\log_2(n!) = \Theta(n \log n)$. Non-comparison sorts escape this bound by using additional information about the key domain.

Worked Example: Counting Sort. Suppose we wish to sort the array $A = [3, 1, 4, 1, 5, 9, 2, 6]$, where every key lies in $\{0, 1, \ldots, k\}$ with $k = 9$.

  • Count. Allocate a count array $C[0{:}k]$ initialised to zero. For each $a \in A$, increment $C[a]$. After this pass, $C[v]$ holds the number of occurrences of value $v$.
  • Cumulate. Replace $C[j] \leftarrow C[j] + C[j-1]$ for $j = 1, \ldots, k$. Now $C[v]$ is the number of elements $\leq v$, giving the final position of the last occurrence of $v$ in the output.
  • Place. Traverse $A$ from right to left; place each element $A[i]$ at output index $C[A[i]] - 1$, then decrement $C[A[i]]$.

    • The result is the sorted array $[1, 1, 2, 3, 4, 5, 6, 9]$.

    Key Theorem (Counting Sort Complexity). Let $n = |A|$ and let every key belong to $\{0, \ldots, k\}$. Counting sort runs in $\Theta(n + k)$ time and uses $\Theta(n + k)$ auxiliary space. When $k = O(n)$, this yields $\Theta(n)$ time — strictly better than the $\Omega(n \log n)$ comparison lower bound.

    Radix sort extends this idea by processing keys digit by digit (from least significant to most significant), applying a stable counting sort at each digit position. For $d$-digit keys in base $b$, Radix sort runs in $\Theta(d(n + b))$ time.

    Lab Cell.

    from sympy import symbols, Function
from collections import Counter

def counting_sort(A, k):
    C = [0] * (k + 1)
    for a in A:
        C[a] += 1
    for j in range(1, k + 1):
        C[j] += C[j - 1]
    output = [0] * len(A)
    for i in range(len(A) - 1, -1, -1):
        output[C[A[i]] - 1] = A[i]
        C[A[i]] -= 1
    return output

A = [3, 1, 4, 1, 5, 9, 2, 6]
print(counting_sort(A, k=9))   # [1, 1, 2, 3, 4, 5, 6, 9]
