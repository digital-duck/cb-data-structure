队列

定义。 队列(queue)是一种遵循先进先出(FIFO, First-In-First-Out)原则的线性集合:元素只能从队尾加入(入队, enqueue),只能从队首移除(出队, dequeue)。最早进入的元素最先被处理,就像排队买票。典型操作如下:

| 操作 | 作用 | 时间复杂度 | |---|---|---| | enqueue(x) | 将 $x$ 加到队尾 | $O(1)$ | | dequeue() | 移除并返回队首元素 | $O(1)$ | | front() | 查看队首元素 | $O(1)$ | | is_empty() | 判断队列是否为空 | $O(1)$ |

在 Python 中应使用 collections.deque 实现队列;若用 list.pop(0),每次出队需移动全部元素,代价为 $O(n)$。

在图遍历中的角色。 广度优先搜索(BFS)用队列来安排"待访问顶点"的顺序:先发现的顶点先被展开,因此搜索会一层一层地向外扩展。

例题。 无向图的邻接表为: $A:\{B,C\}$,$B:\{A,D\}$,$C:\{A,D\}$,$D:\{B,C,E\}$,$E:\{D\}$。从 $A$ 出发做 BFS,写出访问顺序。

from collections import deque

def bfs(graph, start):
    visited = {start}
    queue = deque([start])
    order = []
    while queue:
        v = queue.popleft()          # 出队
        order.append(v)
        for w in graph[v]:
            if w not in visited:
                visited.add(w)       # 入队时即标记,避免重复入队
                queue.append(w)
    return order

队列的变化过程(队首在左):

| 步骤 | 出队 | 入队 | 队列 | |---|---|---|---| | 初始 | — | $A$ | $[A]$ | | 1 | $A$ | $B,C$ | $[B,C]$ | | 2 | $B$ | $D$ | $[C,D]$ | | 3 | $C$ | (D 已标记) | $[D]$ | | 4 | $D$ | $E$ | $[E]$ | | 5 | $E$ | — | $[\,]$ |

访问顺序为 $A,B,C,D,E$。

问题求解应用:最短路径(边数)。 在无权图中,求从起点 $s$ 到各顶点的最少边数。只需在入队时记录距离:若 $w$ 由 $v$ 发现,则 $d(w)=d(v)+1$。

因为队列是先进先出的,所有距离为 $k$ 的顶点一定在所有距离为 $k+1$ 的顶点之前出队。因此每个顶点第一次被发现时所得的距离就是最短距离。上例中 $d(A)=0$,$d(B)=d(C)=1$,$d(D)=2$,$d(E)=3$。

若把队列换成栈(后进先出),遍历就变成深度优先搜索,上述"按层扩展"的性质随之消失,距离也就不再保证最短。

复杂度。 每个顶点至多入队、出队一次,每条边至多被检查常数次,所以 BFS 的总时间为 $O(|V|+|E|)$,队列所需额外空间为 $O(|V|)$。

    B --> C["队列中的顶点依次前移"]
    C --> D["队首"]
    D --> E["出队: 展开该顶点"]
