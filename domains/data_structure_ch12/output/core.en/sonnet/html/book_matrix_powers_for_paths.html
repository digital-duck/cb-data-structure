What Matrix Powers Achieve

Throughout this chapter, each concept has been a stepping stone: matrix representation encodes structure, matrix multiplication propagates information, and repeated multiplication accumulates that propagation over multiple steps. Matrix powers for paths are the natural endpoint because they answer the fundamental question of graph reachability in closed, algebraic form. Given an adjacency matrix $A$ for a graph $G$ on $n$ vertices, the entry $(A^k)_{ij}$ counts the number of distinct walks of length exactly $k$ from vertex $i$ to vertex $j$. The matrix $A^k$ thus transforms a local, edge-by-edge description of a graph into a global, $k$-step picture — without explicit enumeration.

Worked Example. Let $G$ be the triangle graph with vertices $\{1,2,3\}$ and edges $\{(1,2),(2,3),(1,3)\}$, giving

$$A = \begin{pmatrix} 0 & 1 & 1 \\ 1 & 0 & 1 \\ 1 & 1 & 0 \end{pmatrix}.$$

Computing $A^2$ directly yields $(A^2)_{11} = 2$, confirming two walks of length 2 from vertex 1 back to itself: $1\to2\to1$ and $1\to3\to1$. No case analysis is needed; the algebra does the counting automatically.

Key Theorem (Walk-Counting via Powers). For a graph with adjacency matrix $A$, the number of walks of length $k$ from vertex $i$ to vertex $j$ is $(A^k)_{ij}$. Consequently, vertex $j$ is reachable from vertex $i$ within $k$ steps if and only if $\sum_{\ell=1}^{k}(A^\ell)_{ij} > 0$.

Lab Cell

import sympy as sp

A = sp.Matrix([[0,1,1],[1,0,1],[1,1,0]])
for k in range(1, 5):
    print(f"A^{k} =\n{A**k}\n")

Run this cell and observe how rapidly the entries grow; this growth rate is governed by the largest eigenvalue of $A$, a thread that leads directly into spectral graph theory.
