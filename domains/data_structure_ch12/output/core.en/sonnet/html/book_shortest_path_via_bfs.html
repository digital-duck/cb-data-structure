Concept Book: Shortest Path Via Bfs

Payoff

What the Algorithm Achieves

Breadth-First Search (BFS) solves the single-source shortest path problem on unweighted graphs: given a graph $G = (V, E)$ and a source vertex $s \in V$, it computes, for every reachable vertex $v$, the minimum number of edges on any path from $s$ to $v$. This quantity, denoted $d(s, v)$, is the graph-theoretic distance. Because BFS explores vertices in non-decreasing order of their distance from $s$, the first time it reaches $v$ it has necessarily found an optimal route — no shorter path can arrive later. The algorithm runs in $O(|V| + |E|)$ time, making it optimal in the sense that every vertex and every edge must be inspected at least once in the worst case.

Worked Example

Consider the undirected graph $G$ with vertices $\{A, B, C, D, E\}$ and edges $\{AB, AC, BD, BE, CE\}$. Starting BFS at $A$, the queue evolves as follows:

| Step | Queue | Visited | Distance assigned | |------|-------|---------|-------------------| | 0 | $[A]$ | $\{A\}$ | $d(A,A)=0$ | | 1 | $[B,C]$ | $\{A,B,C\}$ | $d(A,B)=d(A,C)=1$ | | 2 | $[C,D,E]$ | $\{A,B,C,D,E\}$ | $d(A,D)=d(A,E)=2$ |

The shortest path from $A$ to $D$ is $A \to B \to D$, of length $2$. No path of length $1$ exists, as $D$ is not adjacent to $A$.

Key Theorem

Theorem (BFS Correctness). Let $G = (V,E)$ be an unweighted graph and $s \in V$. Upon termination of BFS, $d(s,v) = \delta(s,v)$ for every vertex $v$ reachable from $s$, where $\delta(s,v)$ denotes the true shortest-path distance.

The proof proceeds by induction on $\delta(s,v)$. The base case $\delta(s,s) = 0$ is immediate. For the inductive step, any vertex $v$ at distance $k$ has a neighbour $u$ at distance $k-1$; by the inductive hypothesis $u$ is dequeued before $v$ and thus $v$ is enqueued with label $k$ no later than any spurious label could be assigned.

Lab Cell

from collections import deque
import sympy as sp

def shortest_path_via_bfs(graph: dict, source):
    dist = {source: 0}
    prev = {source: None}
    queue = deque([source])
    while queue:
        u = queue.popleft()
        for v in graph.get(u, []):
            if v not in dist:
                dist[v] = dist[u] + 1
                prev[v] = u
                queue.append(v)
    return dist, prev

def reconstruct(prev, target):
    path, node = [], target
    while node is not None:
        path.append(node)
        node = prev[node]
    return list(reversed(path))

G = {'A': ['B','C'], 'B': ['A','D','E'], 'C': ['A','E'],
     'D': ['B'], 'E': ['B','C']}
dist, prev = shortest_path_via_bfs(G, 'A')
print(dist)                       # {'A':0,'B':1,'C':1,'D':2,'E':2}
print(reconstruct(prev, 'D'))     # ['A','B','D']

An Invitation

The ideas consolidated here — layer-by-layer exploration, distance labels, path reconstruction — are the common skeleton beneath routing protocols, social-network analysis, puzzle solvers, and compiler dependency resolution. Each domain reweights or recolours the graph differently, but the BFS invariant remains the engine.
