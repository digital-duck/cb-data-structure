Graph Traversal

Definition. Let $G = (V, E)$ be a graph with vertex set $V$ and edge set $E \subseteq V \times V$. A traversal of $G$ is a systematic procedure that visits every vertex reachable from a designated source $s \in V$ exactly once, recording the order of discovery. The choice of data structure governing which vertex to explore next determines the traversal strategy. Breadth-First Search (BFS) uses a FIFO queue: starting from $s$, BFS discovers all vertices at distance $k$ before any vertex at distance $k+1$, where distance is measured in hop count. This level-by-level expansion is the defining characteristic of BFS and forms the basis for shortest-path computation in unweighted graphs.

Worked Example. Consider the undirected graph $G$ with $V = \{1,2,3,4,5\}$ and edges $E = \{(1,2),(1,3),(2,4),(3,4),(4,5)\}$, with source $s = 1$.

BFS initialises the queue with $[1]$ and marks 1 as visited. It dequeues 1 and enqueues its neighbours $\{2, 3\}$, yielding queue $[2, 3]$. It dequeues 2 and enqueues unvisited neighbour 4, yielding $[3, 4]$. It dequeues 3; neighbour 4 is already visited, so nothing is added. It dequeues 4 and enqueues 5. Finally, it dequeues 5, which has no unvisited neighbours. Discovery order: $1, 2, 3, 4, 5$. Vertices at distance 1 from the source ($\{2,3\}$) appear before those at distance 2 ($\{4\}$), which appear before distance 3 ($\{5\}$), exactly as the definition requires.

Key Theorem (Complexity). For a graph represented as an adjacency list, BFS runs in time $\Theta(|V| + |E|)$ and uses $O(|V|)$ auxiliary space. This linear bound is optimal: any correct traversal must inspect every edge at least once to guarantee reachability.

Proof sketch. Each vertex is enqueued at most once, contributing $O(|V|)$ operations. Each edge $(u,v)$ is examined when $u$ is processed; in an undirected graph each edge appears in two adjacency lists, yielding $2|E|$ edge inspections total. The total work is therefore $O(|V| + |E|)$. The matching lower bound holds because an adversary can hide an unvisited vertex behind any unexamined edge, so no algorithm can do better.

Lab Cell.

import networkx as nx

G = nx.Graph([(1,2),(1,3),(2,4),(3,4),(4,5)])
bfs_order = list(nx.bfs_tree(G, source=1).nodes())
print("BFS:", bfs_order)
