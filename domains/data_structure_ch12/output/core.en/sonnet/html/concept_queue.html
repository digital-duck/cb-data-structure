Queue

Definition. A queue is an abstract data type that maintains a finite sequence of elements subject to the First-In, First-Out (FIFO) discipline: the element that has waited longest is always the next to be removed. Formally, a queue $Q$ over a set $S$ supports four operations:

  • $\mathrm{enqueue}(Q, x)$: append element $x \in S$ to the rear of $Q$.
  • $\mathrm{dequeue}(Q)$: remove and return the element at the front of $Q$; undefined on an empty queue.
  • $\mathrm{peek}(Q)$: return the front element without removing it.
  • $\mathrm{isEmpty}(Q)$: return true if and only if $|Q| = 0$.

    • If we index positions so that the front occupies index $1$ and the rear occupies index $n$, an enqueue increases $n$ by one and a dequeue increases the front pointer by one, leaving all intermediate elements undisturbed.

    Worked Example. Consider the sequence of operations applied to an initially empty queue $Q$:

    $$\mathrm{enqueue}(Q, 3),\quad \mathrm{enqueue}(Q, 7),\quad \mathrm{enqueue}(Q, 1),\quad \mathrm{dequeue}(Q).$$

    After the three enqueue calls the internal sequence is $\langle 3, 7, 1 \rangle$ with $3$ at the front. The dequeue removes $3$ and returns it, leaving $Q = \langle 7, 1 \rangle$. A subsequent $\mathrm{peek}$ returns $7$ without altering $Q$.

    Key Theorem (Amortised Complexity). A queue implemented with two stacks — an inbox and an outbox — supports $n$ intermixed enqueue and dequeue operations in $O(n)$ total time, giving $O(1)$ amortised cost per operation. The proof uses a potential function $\Phi = |\text{inbox}|$. Each enqueue costs $O(1)$ and increases $\Phi$ by $1$; each dequeue costs $O(1)$ amortised because the $O(k)$ transfer from inbox to outbox is charged against the $k$ units of potential stored by prior enqueues, leaving zero net increase. Hence total work is $O(n)$ regardless of the operation ordering.

    Lab Cell.

    from collections import deque
import sympy as sp

Q = deque()
for x in [3, 7, 1]:
    Q.append(x)          # enqueue

front = Q.popleft()      # dequeue → 3
print("Dequeued:", front)
print("Remaining queue:", list(Q))

n = sp.Symbol('n', positive=True)
amortised_cost = sp.Rational(1, 1)   # O(1) per operation
print("Amortised cost per operation:", amortised_cost, "· O(1)")
