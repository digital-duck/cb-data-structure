Vertex Degree

Definition. Let $G = (V, E)$ be an undirected graph with vertex set $V$ and edge set $E \subseteq \binom{V}{2}$. The degree of a vertex $v \in V$, denoted $\deg(v)$, is the number of edges incident to $v$:

$$\deg(v) = \bigl|\{\, e \in E \mid v \in e \,\}\bigr|.$$

A vertex with degree zero is called isolated. In a directed graph, one distinguishes the in-degree $\deg^-(v)$ (edges entering $v$) from the out-degree $\deg^+(v)$ (edges leaving $v$), with $\deg(v) = \deg^-(v) + \deg^+(v)$.

Worked Example. Consider the graph $G$ with $V = \{A, B, C, D\}$ and edges $E = \{AB, AC, BC, CD\}$.

| Vertex | Incident edges | Degree | |--------|---------------|--------| | $A$ | $AB,\, AC$ | $2$ | | $B$ | $AB,\, BC$ | $2$ | | $C$ | $AC,\, BC,\, CD$ | $3$ | | $D$ | $CD$ | $1$ |

Observe that $\sum_{v \in V} \deg(v) = 2 + 2 + 3 + 1 = 8 = 2|E|$, since each edge contributes exactly one to each of its two endpoint degrees.

Theorem (Handshaking Lemma). For any undirected graph $G = (V, E)$,

$$\sum_{v \in V} \deg(v) = 2|E|.$$

Proof sketch. Define the incidence sum $S = \sum_{v \in V} \deg(v)$. Each edge $e = \{u, w\}$ is counted once when $v = u$ and once when $v = w$, contributing exactly $2$ to $S$. Summing over all $|E|$ edges gives $S = 2|E|$. $\square$

An immediate corollary is that every graph contains an even number of vertices of odd degree — a fact used repeatedly in Eulerian circuit theory.

Lab Cell.

import sympy
from sympy.combinatorics.graphs import Graph   # or use networkx as below
import networkx as nx

G = nx.Graph()
G.add_edges_from([("A","B"), ("A","C"), ("B","C"), ("C","D")])

degrees = dict(G.degree())
print("Degree sequence:", sorted(degrees.values(), reverse=True))
print("Sum of degrees:", sum(degrees.values()))
print("2 * |E|:", 2 * G.number_of_edges())

# Verify Handshaking Lemma
assert sum(degrees.values()) == 2 * G.number_of_edges()
