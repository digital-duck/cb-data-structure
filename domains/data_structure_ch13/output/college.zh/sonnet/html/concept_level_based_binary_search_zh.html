基于层级的二分查找

定义。 设整数键取自 $w$ 位二进制全域 $\{0,1,\dots,2^w-1\}$,并存放在深度为 $w$ 的二叉字典树(trie)中:第 $\ell$ 层的节点对应键的长度为 $\ell$ 的前缀。对任意整数 $x$,其搜索路径是从根出发、沿着 $x$ 的各位向下走、直到无法继续为止所经过的节点序列。我们要找的是这条路径上最深的节点,即 $x$ 与已存键的最长公共前缀所对应的节点。

朴素做法逐层下降,耗时 $O(w)$。基于层级的二分查找的思路是:为每一层 $\ell$ 维护一张哈希表 $H_\ell$,存放该层所有节点的标签(即长度为 $\ell$ 的前缀)。于是判断"$x$ 的前 $\ell$ 位前缀是否是 trie 中的节点"只需一次期望 $O(1)$ 的哈希查询。

为什么可以二分。 路径具有单调性:若 $x$ 的长度为 $\ell$ 的前缀在 trie 中存在,则它所有更短的前缀也必然存在。因此谓词 $P(\ell)=[\,x$ 的前 $\ell$ 位 $\in H_\ell\,]$ 先为真、后为假,可以对 $\ell\in[0,w]$ 做二分,求最大的使 $P(\ell)$ 为真的 $\ell$。共需 $O(\log w)$ 次哈希查询。

算法。

def deepest(x, H, w):
    lo, hi = 0, w            # 不变式:P(lo) 为真
    while lo < hi:
        mid = (lo + hi + 1) // 2
        if (x >> (w - mid)) in H[mid]:   # 取前 mid 位
            lo = mid
        else:
            hi = mid - 1
    return lo

例题。 取 $w=4$,键集 $\{0101,\,0110,\,1100\}$,查询 $x=0111$。各层节点标签为:$H_1=\{0,1\}$,$H_2=\{01,11\}$,$H_3=\{010,011,110\}$,$H_4=\{0101,0110,1100\}$。

  • 初始 $lo=0,\ hi=4$。取 $mid=2$:前缀 $01\in H_2$,故 $lo=2$。
  • 取 $mid=3$:前缀 $011\in H_3$,故 $lo=3$。
  • 取 $mid=4$:前缀 $0111\notin H_4$,故 $hi=3$。此时 $lo=hi=3$,结束。

    • 答案为深度 3,节点标签 $011$(对应 $0110$ 的前缀)。仅用 3 次查询,而逐层扫描需要 4 次。

    问题求解应用。 该技术是 y-fast trie 与 van Emde Boas 类结构实现前驱/后继查询的核心:先用二分找到最深节点,再借助该节点上保存的子树最小值或最大值指针,在 $O(1)$ 内得到 $x$ 的前驱或后继。总时间

    $$T(w)=O(\log w)$$

    对 $w=64$ 的整数只需约 6 次哈希查询。

    正确性要点。 循环不变式为:$P(lo)$ 为真,且对所有 $\ell>hi$,$P(\ell)$ 为假。每轮区间 $[lo,hi]$ 的长度至少减半,而由单调性,两种分支都不会丢掉答案。空间代价为 $O(nw)$,因为每个键在每一层各贡献一个前缀;y-fast trie 通过只存每 $w$ 个键中的一个代表来降到 $O(n)$。
