Payoff

What fusion trees achieve. Every data structure encountered in earlier chapters — binary search trees, B-trees, skip lists — performs predecessor queries in $\Theta(\log n)$ comparisons, a bound that the adversary argument proves optimal for comparison-based models. The fusion tree, introduced by Fredman and Willard (1993), escapes this barrier by operating in the word RAM model, where a single machine instruction processes $w$ bits simultaneously. For a static set $S$ of $n$ integers drawn from $\{0, 1, \ldots, 2^w - 1\}$, a fusion tree answers predecessor queries in $O(\log n / \log w)$ time, which for $w = \Theta(\log n)$ gives $O(\log n / \log \log n)$ — a genuine asymptotic improvement over every comparison tree.

Worked example. Let $w = 64$ and $n = 2^{20} \approx 10^6$. A balanced BST requires $\lceil \log_2 n \rceil = 20$ comparisons per query. A fusion tree groups keys into nodes of branching factor $B = w^{1/5} = 64^{1/5} \approx 2.3$, rounded to $B = 2$ at this scale, and packs $B$ compressed keys into a single word. The tree height is $\lceil \log_B n \rceil$, and each level is resolved with $O(1)$ word operations (bitwise sketching, rank via multiplication, and parallel comparison). Even at moderate $n$, cache-oblivious implementations realise the constant-factor gains of reduced tree height.

Key theorem. Fredman–Willard (1993). A set of $n$ $w$-bit integers can be stored in a fusion tree of size $O(n)$ such that predecessor, successor, and membership queries are answered in $O(\log n / \log w)$ worst-case time and insertions in $O(\log n / \log w)$ amortised time (dynamic variant).

The proof constructs a $B$-ary trie compressed by a sketch function $\sigma: \{0,1\}^w \to \{0,1\}^{O(B \log B)}$ that preserves the relative order of keys within a node, then shows that $\sigma$ is computable in $O(1)$ word operations using integer multiplication.

Lab cell.

from sympy import log, symbols, simplify

n, w = symbols('n w', positive=True)
bst_depth  = log(n, 2)
fusion_depth = log(n, 2) / log(w, 2)
speedup = simplify(bst_depth / fusion_depth)
print("Asymptotic speedup factor:", speedup)   # → log(w)

# Concrete values
import math
for bits in [16, 32, 64]:
    ratio = math.log2(bits)
    print(f"w={bits}: fusion tree is {ratio:.1f}× shallower than BST")

With the fusion tree in hand, the path forward opens into integer sorting in $O(n \log n / \log \log n)$ time, succinct data structures for computational geometry, and cache-efficient database indexing — each domain inheriting the same word-level parallelism that powers this chapter's central insight. Choose one: the geometry strand, where fusion trees underlie optimal orthogonal range-searching, offers perhaps the richest first excursion into how algebraic structure and bit-manipulation conspire to shatter classical lower bounds.
