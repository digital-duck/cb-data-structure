Concept Book: Van Emde Boas Tree

Data Structure Ch13 · Generated by SPL

Payoff

What the Structure Achieves

A van Emde Boas tree (vEB tree) is a data structure that supports the operations of a priority queue—insert, delete, find-minimum, find-maximum, successor, and predecessor—on a universe $\mathcal{U} = \{0, 1, \ldots, u-1\}$ of integer keys in worst-case time $O(\log \log u)$ per operation, using $O(u)$ space. To appreciate the significance of this bound, recall that a balanced binary search tree achieves $O(\log n)$ time, where $n$ is the number of stored elements. When $u$ is fixed and $n \approx u$, vEB time collapses to $O(\log \log u)$—a doubly-logarithmic quantity that is effectively a small constant for any universe encountered in practice.

Definition. For universe size $u = 2^{2^k}$, the vEB tree $V(u)$ is defined recursively. It maintains a summary structure $V(\sqrt{u})$ and $\sqrt{u}$ cluster structures, each also of type $V(\sqrt{u})$. A key $x \in \mathcal{U}$ is decomposed as $x = \lfloor x / \sqrt{u} \rfloor \cdot \sqrt{u} + (x \bmod \sqrt{u})$, where the first component selects a cluster and the second gives a position within it.

Worked Example: Successor Query

Suppose $u = 16$ and the stored set is $S = \{2, 5, 11, 14\}$. Query: find the successor of $6$.

  • Compute cluster index $c = \lfloor 6/4 \rfloor = 1$ and position $p = 6 \bmod 4 = 2$.
  • Check cluster 1 for any element with position $> 2$. Cluster 1 stores $\{5\}$, with position $1 < 2$; no successor found locally.
  • Consult the summary to find the next non-empty cluster: cluster index $2$ (containing $\{11\}$).
  • Return the minimum of cluster 2: position $3$, so the successor is $2 \cdot 4 + 3 = 11$.

    • Each step recurses on a structure of size $\sqrt{u}$, yielding the recurrence $T(u) = T(\sqrt{u}) + O(1)$, which solves to $T(u) = O(\log \log u)$.

    Key Theorem

    Theorem (vEB complexity). Every operation on a van Emde Boas tree over universe $\{0,\ldots,u-1\}$ runs in $O(\log \log u)$ worst-case time.

    Proof sketch. The recurrence $T(u) = T(u^{1/2}) + O(1)$ is solved by the substitution $m = \log u$, giving $T(2^m) = T(2^{m/2}) + O(1)$, i.e., $f(m) = f(m/2) + O(1)$, whose solution is $f(m) = O(\log m) = O(\log \log u)$. $\blacksquare$

    Lab Cell

    from sympy import symbols, log, simplify, Function

u = symbols('u', positive=True)

# Verify the recurrence solution symbolically
T = Function('T')
# Substitution: let m = log(u, 2), so T(2**m) satisfies g(m) = g(m/2) + 1
m = symbols('m', positive=True)

# g(m) = log(m) satisfies log(m) = log(m/2) + log(2)/log(2), i.e., same recurrence up to constant
g = log(m)
residual = simplify(g - (g.subs(m, m/2) + 1))
print("Residual (should be ~0 up to constant):", residual)

# Numerical illustration: how small is log(log(u)) for large u?
import math
for exp in [16, 32, 64]:
    uu = 2**exp
    print(f"u = 2^{exp} = {uu:.2e},  log₂(log₂(u)) = {math.log2(math.log2(uu)):.2f}")

    Running this cell for $u = 2^{64}$ reveals $\log_2 \log_2 u = 6$—meaning that across the entire 64-bit integer universe, every successor query touches at most six recursive levels.
