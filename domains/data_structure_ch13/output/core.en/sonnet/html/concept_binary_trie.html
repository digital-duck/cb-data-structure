Binary Trie

Definition. A binary trie (from retrieval) is a rooted tree in which every internal node has exactly two children, labelled $0$ and $1$, and each node at depth $d$ represents the set of all binary strings sharing a common prefix of length $d$. Formally, let $\Sigma = \{0,1\}$. A binary trie over a finite set $S \subseteq \Sigma^*$ is the smallest rooted binary tree $T$ such that for every string $s = s_1 s_2 \cdots s_k \in S$ there exists a root-to-node path whose edge labels spell out $s_1, s_2, \ldots, s_k$. Nodes terminating a stored string are marked; unmarked internal nodes act purely as routing structure.

Worked Example. Insert the strings $\{0,01,10,110\}$ into an initially empty trie. Starting from the root:

  • String $0$: follow edge $0$; mark that node.
  • String $01$: follow edge $0$, then edge $1$; mark the resulting leaf.
  • String $10$: follow edge $1$, then edge $0$; mark that leaf.
  • String $110$: follow edge $1$, then edge $1$, then edge $0$; mark the final node.

    • The trie has depth $3$ and seven nodes in total (root plus six descendants). A membership query for $10$ costs exactly $2$ edge traversals — proportional to the length of the query string, not the size of $S$.

    Key Theorem (Query Complexity). Let $T$ be a binary trie storing a set $S$ of binary strings, and let $\ell_{\max} = \max_{s \in S} |s|$. Then membership, insertion, and deletion each run in $O(\ell_{\max})$ time and require at most $O(|S| \cdot \ell_{\max})$ nodes in the worst case, with the best case (maximally shared prefixes) reducing node count to $O(\ell_{\max})$.

    Proof sketch. Each operation traverses at most one root-to-leaf path of length $\leq \ell_{\max}$, performing $O(1)$ work per node. Node count is bounded by summing, over all strings, the number of nodes not shared with a previously inserted string; in the worst case (no shared prefixes) this is $|S| \cdot \ell_{\max}$. $\square$

    from sympy import symbols

class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False

def insert(root, s):
    node = root
    for bit in s:
        node = node.children.setdefault(bit, TrieNode())
    node.is_end = True

def search(root, s):
    node = root
    for bit in s:
        if bit not in node.children:
            return False
        node = node.children[bit]
    return node.is_end

root = TrieNode()
for w in ["0", "01", "10", "110"]:
    insert(root, w)

print(search(root, "10"))   # True
print(search(root, "11"))   # False
