Bit Representation

Definition. Every integer and real number stored in a digital computer is encoded as a finite sequence of bits, each belonging to the set $\{0, 1\}$. For a non-negative integer $n$, the binary representation is the unique tuple $(b_{k-1}, b_{k-2}, \ldots, b_1, b_0)$ with each $b_i \in \{0,1\}$ satisfying

$$n = \sum_{i=0}^{k-1} b_i \cdot 2^i.$$

The integer $k$ is the bit-width. A signed integer is typically encoded using two's complement: for a $k$-bit word, the value of a pattern $(b_{k-1}, \ldots, b_0)$ is

$$n = -b_{k-1} \cdot 2^{k-1} + \sum_{i=0}^{k-2} b_i \cdot 2^i,$$

placing the representable range at $[-2^{k-1},\, 2^{k-1}-1]$.

Worked Example. Convert $n = 45$ to an 8-bit two's complement word.

  • Repeated division by 2: $45 = 32 + 8 + 4 + 1 = 2^5 + 2^3 + 2^2 + 2^0$.
  • Set $b_5 = b_3 = b_2 = b_0 = 1$, all others $0$.
  • Result: $\mathtt{0010\,1101}_2$.

    • Verification: $0\cdot2^7 + 0\cdot2^6 + 1\cdot2^5 + 0\cdot2^4 + 1\cdot2^3 + 1\cdot2^2 + 0\cdot2^1 + 1\cdot2^0 = 32+8+4+1 = 45$. $\checkmark$

    Key Theorem (Uniqueness of Binary Expansion). For every integer $n \geq 0$ there exists a unique finite sequence $(b_{k-1}, \ldots, b_0)$ with $b_{k-1} = 1$ (unless $n = 0$) such that $n = \sum_{i=0}^{k-1} b_i 2^i$. The proof follows by strong induction: the base case $n \in \{0,1\}$ is immediate; for $n \geq 2$, write $n = 2q + r$ with $r = n \bmod 2$, apply the inductive hypothesis to $q$, and prepend $r$. Uniqueness follows because the map $\mathbb{Z}/2^k\mathbb{Z} \to \{0,1\}^k$ is a bijection.

    Lab Cell.

    from sympy import Integer

n = Integer(45)
bits = bin(int(n))          # built-in binary string
print(bits)                 # 0b101101

# reconstruct from bit positions
positions = [i for i, ch in enumerate(reversed(bits[2:])) if ch == '1']
reconstructed = sum(2**i for i in positions)
print(reconstructed == int(n))  # True
