Jump Pointers

Definition. Let $T = (V, E)$ be a rooted tree with $n$ nodes and root $r$. For each node $v \in V$ and non-negative integer $k$, the jump pointer $\text{up}[v][k]$ denotes the $2^k$-th ancestor of $v$ in $T$; that is, the unique node reached by following $2^k$ parent edges from $v$ toward the root. Formally,

$$\text{up}[v][0] = \text{parent}(v), \qquad \text{up}[v][k] = \text{up}[\,\text{up}[v][k-1]\,][k-1], \quad k \geq 1.$$

If $v$ has fewer than $2^k$ ancestors, the pointer is conventionally set to a sentinel (often the root or a null node). This recurrence expresses the key structural invariant: the $2^k$-th ancestor equals the $2^{k-1}$-th ancestor of the $2^{k-1}$-th ancestor—a doubling identity that underpins the technique's efficiency.

Worked Example. Consider the path $1 \to 2 \to 3 \to 4 \to 5$ rooted at node $1$, where each edge leads from parent to child. For node $v = 5$ and levels $k = 0, 1, 2$:

$$\text{up}[5][0] = 4, \quad \text{up}[5][1] = \text{up}[4][0] = 3, \quad \text{up}[5][2] = \text{up}[3][1] = \text{up}[\text{up}[3][0]][0] = \text{up}[2][0] = 1.$$

To find the $3$rd ancestor of $5$, write $3 = 2^1 + 2^0$ in binary. Apply: first jump $2^1 = 2$ steps to reach node $3$, then jump $2^0 = 1$ step to reach node $2$. The answer is $2$, obtained in two table lookups.

Key Theorem. After $\mathcal{O}(n \log n)$ preprocessing time and space to populate the jump-pointer table, the $d$-th ancestor of any node can be computed in $\mathcal{O}(\log n)$ time.

Proof sketch. The table has $n \cdot \lceil \log_2 n \rceil$ entries, each computable in $\mathcal{O}(1)$ via the recurrence, giving the preprocessing bound. For a query $d$, decompose $d$ in binary using at most $\lceil \log_2 n \rceil$ bits; each set bit corresponds to one table lookup and one pointer traversal, yielding $\mathcal{O}(\log n)$ total steps. $\blacksquare$

This technique forms the backbone of the $\mathcal{O}(n \log n, \log n)$ algorithm for Lowest Common Ancestor (LCA) queries.

Lab Cell.

import sympy as sp

# Build jump-pointer table for a path graph: parent[i] = i-1, root = 1
n = 8
LOG = n.bit_length()
parent = {i: i - 1 for i in range(2, n + 1)}
parent[1] = 1  # root points to itself as sentinel

up = [[None] * (n + 1) for _ in range(LOG)]
for v in range(1, n + 1):
    up[0][v] = parent[v]
for k in range(1, LOG):
    for v in range(1, n + 1):
        up[k][v] = up[k-1][up[k-1][v]]

def kth_ancestor(v, d):
    for k in range(LOG):
        if (d >> k) & 1:
            v = up[k][v]
    return v

# Verify: 3rd ancestor of 5 in path 1->2->...->8
print(kth_ancestor(5, 3))  # Expected: 2
