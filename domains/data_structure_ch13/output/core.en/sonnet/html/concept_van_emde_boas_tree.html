Van Emde Boas Tree

Definition. A van Emde Boas tree (vEB tree) is a recursive data structure that supports a dynamic set of integers drawn from the universe $U = \{0, 1, \ldots, u-1\}$, where $u = 2^{2^k}$ for some non-negative integer $k$. It supports the operations $\textsc{Insert}$, $\textsc{Delete}$, $\textsc{Successor}$, $\textsc{Predecessor}$, $\textsc{Minimum}$, and $\textsc{Maximum}$, each in $O(\log \log u)$ worst-case time. The structure stores a $\textit{min}$ and $\textit{max}$ element directly, a summary sub-tree over $\sqrt{u}$ clusters, and an array of $\sqrt{u}$ child sub-trees each of universe size $\sqrt{u}$.

Formally, for universe size $u > 2$, a vEB tree $V$ contains:

$$V.\textit{min},\; V.\textit{max} \in \{-\infty\} \cup U,$$ $$V.\textit{summary} : \text{vEB}(\lceil\sqrt{u}\rceil), \quad V.\textit{cluster}[0 \ldots \lfloor\sqrt{u}\rfloor - 1] : \text{vEB}(\lceil\sqrt{u}\rceil).$$

An integer $x$ is split into a high part $h = \lfloor x / \lfloor\sqrt{u}\rfloor \rfloor$ and a low part $\ell = x \bmod \lfloor\sqrt{u}\rfloor$, so $x$ is stored in cluster $h$ at position $\ell$.

Worked Example. Let $u = 16$ and $S = \{2, 3, 8, 11\}$. Here $\sqrt{u} = 4$, so clusters are indexed $0, 1, 2, 3$. We record $\textit{min} = 2$, $\textit{max} = 11$. Element $3$ has $h = 0$, $\ell = 3$; element $8$ has $h = 2$, $\ell = 0$; element $11$ has $h = 2$, $\ell = 3$. Cluster $0$ holds $\{3\}$, cluster $2$ holds $\{0, 3\}$, and the summary records $\{0, 2\}$. A $\textsc{Successor}(9)$ query computes $h = 2$, $\ell = 1$, finds a successor in cluster $2$ (namely $\ell = 3$, giving $x = 11$), and returns $11$ without consulting other clusters.

Theorem (Time Complexity). Every operation on a vEB tree over universe $U$ runs in $O(\log \log u)$ time.

Proof sketch. Each recursive call reduces the universe size from $u$ to $\sqrt{u}$. Setting $T(u)$ as the operation cost satisfies the recurrence $T(u) = T(\sqrt{u}) + O(1)$. Substituting $m = \log u$ yields $T(2^m) = T(2^{m/2}) + O(1)$, whose solution is $T = O(\log m) = O(\log \log u)$. $\square$

Lab Cell.

from sympy import factorint, log, Integer

u = Integer(2**16)
depth = 0
size = u
while size > 2:
    size = size**Integer(1, 2)   # take square root
    depth += 1

print(f"Universe size : {u}")
print(f"Recursion depth (≈ log log u): {depth}")
print(f"log₂(log₂(u)) = {log(log(u, 2), 2).evalf():.3f}")
