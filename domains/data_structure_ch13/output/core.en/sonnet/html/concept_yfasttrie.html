Yfasttrie

Definition. Let $U = 2^w$ be a universe of non-negative integers. A Y-fast trie (Willard, 1983) is a dynamic ordered-set data structure over a subset $S \subseteq \{0, 1, \ldots, U-1\}$ of size $n$ that supports predecessor and successor queries in $O(\log \log U)$ worst-case time, and insertions and deletions in $O(\log \log U)$ expected amortised time, using $O(n)$ space.

The structure builds on the X-fast trie, which stores one hash table $H_i$ for each level $i \in \{0, 1, \ldots, w\}$ of a binary trie. Each $H_i$ maps a $i$-bit prefix to a pointer to that trie node. A predecessor query on an X-fast trie binary-searches over levels to locate the deepest ancestor of the query key, taking $O(\log w) = O(\log \log U)$ time, but an X-fast trie alone requires $O(n \log U)$ space.

The Y-fast trie reduces space by partitioning $S$ into $\lceil n / \log U \rceil$ contiguous clusters, each of size $\Theta(\log U)$. Within each cluster the elements are stored in a balanced binary search tree (e.g., a red-black tree). A single representative from each cluster—its minimum element—is inserted into an underlying X-fast trie. A predecessor query for key $q$ first searches the X-fast trie for the representative immediately above or below $q$ in $O(\log \log U)$ time, then descends into the corresponding BST and performs a standard predecessor search in $O(\log \log U)$ time, since each BST has $O(\log U)$ keys. Both phases share the same asymptotic bound.

Worked example. Take $w = 4$ ($U = 16$) and $S = \{1, 3, 5, 9, 11, 14\}$. With $\log U = 4$, the six elements form two clusters: $C_1 = \{1, 3, 5\}$ and $C_2 = \{9, 11, 14\}$. Representatives $\{1, 9\}$ enter the X-fast trie. A predecessor query for $q = 10$: the X-fast trie returns representative $9$, directing us to $C_2$; the BST over $C_2$ then finds $\text{pred}(10) = 9$ in $O(\log 3)$ steps.

Theorem (Willard 1983). A Y-fast trie on $n$ keys from universe $\{0,\ldots,2^w-1\}$ occupies $O(n)$ space and answers predecessor queries in $O(\log \log U)$ worst-case time.

Proof sketch. Space follows because $O(n / \log U)$ representatives contribute $O(n)$ hash-table entries across all $w+1$ levels of the X-fast trie ($O(n / \log U \cdot \log U) = O(n)$), and the BSTs collectively hold $n$ keys. The query bound combines the $O(\log \log U)$ binary search over trie levels with the $O(\log \log U)$ BST descent. $\square$

# Lab cell — predecessor via sorted list (toy demo; real impl uses hash tries)
from sortedcontainers import SortedList

S = SortedList([1, 3, 5, 9, 11, 14])

def predecessor(S: SortedList, q: int):
    idx = S.bisect_left(q) - 1
    return S[idx] if idx >= 0 else None

print(predecessor(S, 10))   # 9
print(predecessor(S, 5))    # 3
print(predecessor(S, 1))    # None
