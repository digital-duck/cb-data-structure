Array Stack

数组栈是一种用固定大小数组实现的后进先出（LIFO）数据结构。与链表栈不同，数组栈在内存中连续存储元素，并用一个整数指针 top 记录栈顶位置。当 top == -1 时栈为空；当 top == capacity - 1 时栈满。核心操作只有三个：push（压栈）、pop（弹栈）和 peek（查看栈顶），时间复杂度均为 $O(1)$。

实现示例

下面用 Python 实现一个容量为 5 的整数栈：

class ArrayStack:
    def __init__(self, capacity=5):
        self._data = [None] * capacity
        self._top = -1
        self._cap = capacity

    def push(self, val):
        if self._top == self._cap - 1:
            raise OverflowError("栈已满")
        self._top += 1
        self._data[self._top] = val

    def pop(self):
        if self._top == -1:
            raise IndexError("栈为空")
        val = self._data[self._top]
        self._top -= 1
        return val

    def peek(self):
        if self._top == -1:
            raise IndexError("栈为空")
        return self._data[self._top]

    def is_empty(self):
        return self._top == -1

依次执行 push(10)、push(20)、push(30) 后，数组内部状态为 [10, 20, 30, None, None]，top = 2。调用 pop() 返回 30，top 变回 1——元素本身仍留在数组中，但对外不可见，因为 top 已经越过它。

实际应用：括号匹配

给定字符串 "({[]})" ，判断括号是否合法。遍历每个字符：遇到左括号则压栈；遇到右括号则弹栈并检查是否匹配；遍历结束后栈为空则合法，否则非法。

def is_balanced(s):
    stack = ArrayStack(capacity=len(s))
    pairs = {')': '(', ']': '[', '}': '{'}
    for ch in s:
        if ch in '([{':
            stack.push(ch)
        elif ch in ')]}':
            if stack.is_empty() or stack.pop() != pairs[ch]:
                return False
    return stack.is_empty()

print(is_balanced("({[]})"))  # True
print(is_balanced("({[})"))   # False

使用数组栈的关键优势在于内存布局紧凑、缓存友好，适合括号匹配、表达式求值、函数调用帧等场景。需要注意的是，固定容量意味着必须提前估算最大深度；若深度不可预测，应改用动态数组或链表栈。
