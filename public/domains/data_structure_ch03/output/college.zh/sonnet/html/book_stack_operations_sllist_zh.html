收获(Payoff)

一、$\texttt{stack\_operations\_sllist}$ 达成了什么

我们从单向链表(singly linked list)的节点结构出发:每个节点保存一个值 data 和一个指向下一节点的指针 next。把链表的头部当作栈顶,就得到了栈的完整实现:

class Node:
    def __init__(self, data, nxt=None):
        self.data, self.next = data, nxt

class Stack:
    def __init__(self):
        self.head, self.size = None, 0

    def push(self, x):            # O(1)
        self.head = Node(x, self.head)
        self.size += 1

    def pop(self):                # O(1)
        if self.head is None:
            raise IndexError("栈为空")
        x, self.head = self.head.data, self.head.next
        self.size -= 1
        return x

    def peek(self):               # O(1)
        return self.head.data

其核心结论是:$\text{push}$、$\text{pop}$、$\text{peek}$ 的时间复杂度均为 $O(1)$,且不需要像动态数组那样偶尔扩容复制。因为所有操作只触及头节点,指针的改动是常数步,所以 $n$ 次操作的总代价恰为 $\Theta(n)$,而不仅仅是均摊意义上的 $O(n)$。

为什么它是自然的终点? 它把前面学过的三件事汇合在一起:指针与节点(数据如何被"链"起来)、抽象数据类型(只暴露 LIFO,即后进先出的接口)、复杂度分析(用 $O(1)$ 证明设计合理)。再往后的结构,几乎都是在这个"受限访问 + 常数代价"的模式上叠加功能。

二、它通向哪些应用

1. 函数调用与递归。 每次调用把一个栈帧压入调用栈,返回时弹出。递归深度 $d$ 对应栈高度 $d$;"栈溢出"就是 $d$ 超过上限。理解了 push/pop,就能把递归改写为显式栈的迭代,例如用栈实现深度优先遍历。

2. 表达式求值与括号匹配。 遇到左括号 ( 就压栈,遇到右括号 ) 就弹栈,若弹栈时栈空,或结束时栈非空,则括号不匹配。后缀表达式 $3\;4\;+\;2\;\times$ 的求值同理:数字入栈,运算符弹出两个操作数,再把结果压回,最终得 $(3+4)\times 2=14$。

3. 撤销(Undo)与回溯。 编辑器把每次操作压栈,撤销就是 pop 并反向执行。迷宫求解、数独等回溯算法中,栈保存"可退回的决策路径"。

4. 浏览器历史与编译器。 "后退"按钮即弹出栈顶页面;编译器用栈管理作用域和语法分析中的符号。
