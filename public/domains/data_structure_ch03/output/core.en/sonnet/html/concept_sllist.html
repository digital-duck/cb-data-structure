Sllist

A singly linked list (abbreviated sllist) is a linear data structure in which each element, called a node, stores a value and a single reference—called the next pointer—to the immediately following node. The final node carries a null reference, conventionally written $\text{None}$, to signal the end of the sequence.

Definition. A singly linked list $L$ over a set $S$ is a pair $(V, \sigma)$ where $V$ is a finite ordered sequence of nodes $v_1, v_2, \ldots, v_n$ and $\sigma : V \setminus \{v_n\} \to V$ is an injective successor function satisfying $\sigma(v_i) = v_{i+1}$ for $1 \le i < n$. The node $v_1$ is called the head; $v_n$ is called the tail.

Unlike an array, which occupies a contiguous block of memory indexed by position, a singly linked list stores nodes at arbitrary memory addresses and encodes ordering solely through the chain of next pointers. Consequently, accessing the $k$-th element requires traversing $k-1$ pointers, giving $O(k)$ access time, whereas prepending a new head requires only pointer manipulation in $O(1)$ time.

Worked Example. Suppose we maintain the list $L = \langle 3, 7, 2 \rangle$. The nodes occupy addresses $a_1, a_2, a_3$ with $\sigma(a_1)=a_2$, $\sigma(a_2)=a_3$, and $\sigma(a_3)=\text{None}$. To prepend the value $5$, we allocate a new node $a_0$ at any free address, set $a_0.\text{val} = 5$ and $a_0.\text{next} = a_1$, then reassign the head to $a_0$. The resulting list $\langle 5, 3, 7, 2\rangle$ required no movement of existing nodes.

Theorem (Traversal Complexity). For a singly linked list of length $n$, a full traversal visits every node exactly once and performs $n-1$ pointer dereferences, yielding time complexity $\Theta(n)$ and space complexity $O(1)$ (excluding the list itself).

Proof sketch. Starting at the head, each step follows exactly one next pointer and visits one unvisited node. Because the structure is acyclic (the successor function is injective and $\sigma(v_n)=\text{None}$), the traversal terminates after precisely $n$ visits. No auxiliary storage beyond a single cursor variable is required. $\square$

from sympy import symbols, Function

# Build a minimal singly linked list in pure Python
class Node:
    def __init__(self, val, nxt=None):
        self.val, self.next = val, nxt

def from_list(xs):
    head = None
    for x in reversed(xs):
        head = Node(x, head)
    return head

def traverse(head):
    steps, cur = 0, head
    while cur:
        print(cur.val, end=" -> ")
        cur, steps = cur.next, steps + 1
    print("None")
    return steps

head = from_list([3, 7, 2])
new_head = Node(5, head)          # O(1) prepend
n = traverse(new_head)            # prints: 5 -> 3 -> 7 -> 2 -> None
print(f"Nodes visited: {n}")      # Nodes visited: 4

Experiment by prepending several elements and verifying that the traversal count always equals the list length, confirming the $\Theta(n)$ bound empirically.
