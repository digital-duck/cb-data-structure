跳表列表(Skiplist List)

定义

跳表列表用跳表实现 List 接口,支持 $\texttt{get}(i)$、$\texttt{set}(i,x)$、$\texttt{add}(i,x)$、$\texttt{remove}(i)$。关键思想是给每条边附加一个长度 $\ell$:一条边的长度等于它在最底层(第 0 层)跨过的节点数。底层每条边长度为 $1$;高层的边"跳过"更多节点,长度更大。

每个节点的高度 $h$ 随机决定:从 $h=0$ 开始,不断抛硬币,每次正面则 $h \leftarrow h+1$,直到出现反面。因此 $\Pr[h \ge k]=2^{-k}$,节点期望高度为 $1$,总空间期望为 $O(n)$。

核心不变量:从哨兵节点出发,沿路径累加所经过边的长度,得到的和就是当前节点的下标(哨兵记为 $-1$)。

例题

设列表为 $[a,b,c,d,e,f]$,下标 $0\sim5$,求 $\texttt{get}(4)$。

搜索从最高层的哨兵出发,记当前位置 $j=-1$。规则:在第 $r$ 层,若 $j+\ell \le i$,就沿边前进并令 $j \leftarrow j+\ell$;否则下降一层。假设 $c$(下标 2)高度为 3,$e$(下标 4)高度为 2,其余为 1:

  • 第 2 层:哨兵→$c$,长度 $\ell=3$,$j=-1+3=2\le 4$,前进,$j=2$。
  • 第 2 层:$c$→末尾,$j+\ell>4$,下降。
  • 第 1 层:$c\to e$,$\ell=2$,$j=4\le4$,前进,$j=4$。
  • 到达 $j=i$,返回 $e$ 的值。

    • 只走了 $2$ 条边,而不是 $5$ 步线性扫描。

    问题求解应用

    add$(i,x)$:先抽取新节点高度 $k$,然后从上往下搜索。在每一层 $r \le k$,新节点插在"位置 $i$ 之前"的前驱 $u_r$ 之后。设 $u_r$ 在该层原边长为 $\ell$,且 $u_r$ 的下标为 $j$,则新边长度为:

    $$\ell_{\text{前}} = i - j,\qquad \ell_{\text{后}} = \ell - (i-j) + 1.$$

    高于 $k$ 的层,经过插入点的边长度各加 $1$(因为多了一个节点)。remove$(i)$ 对称:被删节点所在各层,前驱边长度变为 $\ell_{\text{前}}+\ell_{\text{后}}-1$;更高层经过它的边长度减 $1$。

    复杂度分析:搜索路径的反向分析是经典技巧。从目标节点倒着走:每一步以概率 $1/2$ 向上(该节点高度更高),以概率 $1/2$ 向左。向上最多 $O(\log n)$ 次(期望层数为 $\log n + O(1)$),而期望每上升一层只需向左 $1$ 步,因此期望路径长度为

    $$\mathbb{E}[\text{path}] \le 2\log_2 n + O(1)=O(\log n).$$

    所有四种操作都由一次自顶向下的搜索加上每层 $O(1)$ 的长度调整组成,所以期望时间均为 $O(\log n)$。

    练习:若把抛硬币的概率由 $1/2$ 改为 $p$,期望空间与搜索路径长度如何变化?(提示:期望高度为 $\tfrac{p}{1-p}$,每层期望横向步数为 $\tfrac1p$。)
