Concept Book: Skiplist List

Data Structure Ch04 · Generated by SPL

Payoff

A skip list is a randomised, layered linked structure that achieves the same asymptotic performance as a balanced binary search tree—$O(\log n)$ expected time for search, insertion, and deletion—without requiring explicit rebalancing. The skiplist_list abstraction formalises this idea as an ordered sequence of levels $L_0 \supset L_1 \supset \cdots \supset L_{\lfloor \log_2 n \rfloor}$, where every element appears in $L_0$ and each element is independently promoted to level $L_{k+1}$ with probability $p \in (0,1)$.

Definition. A skiplist_list over a totally ordered set $(U, \leq)$ with promotion probability $p$ is a tuple $(H, \{L_k\}_{k \geq 0})$, where $H$ is a sentinel head node present at every level and each $L_k$ is a sorted singly-linked list satisfying $L_{k+1} \subseteq L_k$. A search for key $x$ begins at the topmost non-empty level, advances right while the next key does not exceed $x$, then drops one level, repeating until $L_0$ is reached.

Worked example. Insert the sequence $\{3, 7, 12, 19, 26\}$ with $p = 1/2$. Suppose the coin-flip outcomes assign node $12$ to levels $0$–$2$ and all others to level $0$ only. Then $L_2 = \{12\}$, $L_1 = \{12\}$, $L_0 = \{3, 7, 12, 19, 26\}$. A search for $19$ begins at $L_2$, finds $12 < 19$ and advances right to the sentinel, drops to $L_1$, repeats, drops to $L_0$, and walks $12 \to 19$ in one step—four comparisons total versus five in a naïve linear scan.

Theorem (expected search cost). For a skiplist_list of $n$ elements with promotion probability $p$, the expected number of comparisons to locate any key is $\mathbb{E}[C] = \log_{1/p} n + \dfrac{1}{1-p}$.

Proof sketch. The backward analysis of Pugh (1990) models the search path in reverse as a Markov chain ascending levels; the expected climb height contributes $\log_{1/p} n$ and the expected horizontal steps per level contribute $1/(1-p)$, yielding the stated bound. $\square$

The skiplist_list is the natural endpoint of this textbook because it synthesises every preceding concept—ordered sequences, probabilistic promotion, pointer arithmetic, and recurrence analysis—into a single structure that is both theoretically clean and practically deployable. Its sorted-order guarantee pairs directly with range-query engines in database indices, where a scan from key $a$ to key $b$ requires only $O(\log n + k)$ time for $k$ results. The same structure underpins lock-free concurrent maps, since each level can be updated with atomic compare-and-swap operations without global locking. In approximate nearest-neighbour search, hierarchical skip levels mirror the coarse-to-fine strategy of navigable small-world graphs. And in streaming algorithms, a skiplist_list maintained over a sliding window supports order-statistic queries in sub-linear space relative to the full history.

Each of these domains rewards the reader who invests in understanding the structure deeply.
