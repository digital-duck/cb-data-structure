Edge Length

Definition. Let $G = (V, E)$ be a graph embedded in a metric space $(M, d)$, where $V$ is the set of vertices and $E \subseteq V \times V$ is the set of edges. For an edge $e = (u, v) \in E$, the edge length is defined as

$$\ell(e) = d(u, v),$$

where $d : M \times M \to \mathbb{R}_{\geq 0}$ is the metric on $M$. When $G$ is embedded in Euclidean space $\mathbb{R}^n$, the edge length reduces to the standard Euclidean distance:

$$\ell(u, v) = \left\lVert \mathbf{p}_u - \mathbf{p}_v \right\rVert_2 = \sqrt{\sum_{k=1}^{n} (p_{u,k} - p_{v,k})^2},$$

where $\mathbf{p}_u, \mathbf{p}_v \in \mathbb{R}^n$ are the coordinate vectors of $u$ and $v$, respectively. In unweighted combinatorial graphs, all edges are assigned unit length by convention, so $\ell(e) = 1$ for every $e \in E$.

Worked Example. Consider a triangle graph $G$ with vertices $A = (0, 0)$, $B = (3, 0)$, and $C = (0, 4)$ embedded in $\mathbb{R}^2$. The three edge lengths are:

$$\ell(A, B) = \sqrt{(3-0)^2 + (0-0)^2} = 3, \quad \ell(A, C) = \sqrt{0 + 16} = 4,$$ $$\ell(B, C) = \sqrt{9 + 16} = 5.$$

The total perimeter of the graph is $\sum_{e \in E} \ell(e) = 3 + 4 + 5 = 12$, and the edge $(B, C)$ is the longest, confirming the 3-4-5 Pythagorean triple.

Theorem (Triangle Inequality for Edge Lengths). For any three vertices $u, v, w \in V$ in a metric-space embedding,

$$\ell(u, w) \leq \ell(u, v) + \ell(v, w).$$

Proof sketch. This follows directly from the triangle inequality axiom of the metric $d$. Equality holds if and only if $v$ lies on a shortest path between $u$ and $w$.

This property is foundational in shortest-path algorithms: the shortest path between two vertices cannot be shorter than the direct edge length, ensuring the optimality conditions of algorithms such as Dijkstra's.

from sympy import symbols, sqrt, Rational, simplify

# Vertex coordinates
A, B, C = (0, 0), (3, 0), (0, 4)

def edge_length(p, q):
    return sqrt(sum((pi - qi)**2 for pi, qi in zip(p, q)))

lab = {
    "AB": edge_length(A, B),
    "AC": edge_length(A, C),
    "BC": edge_length(B, C),
}

for name, length in lab.items():
    print(f"ℓ({name}) = {simplify(length)}")

print("Perimeter =", sum(lab.values()))
