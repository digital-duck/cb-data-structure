Hash Function

Definition. A hash function is a map $h : U \to \{0, 1, \ldots, m-1\}$ from a (typically large) universe $U$ of keys to a finite set of buckets of size $m$. For the function to be useful in practice it must be (i) deterministic—equal inputs always produce equal outputs—(ii) efficient to evaluate in $O(1)$ time, and (iii) uniform in the sense that, for a randomly chosen key $k \in U$, each bucket index $j$ satisfies $\Pr[h(k) = j] \approx 1/m$. A hash function used for data structures need not be cryptographically secure; a hash function used for message authentication must additionally be collision-resistant and one-way.

Worked Example. Let $U = \mathbb{Z}$ and $m = 7$. The division method defines

$$h(k) = k \bmod m.$$

For the key sequence $k \in \{14, 3, 22, 9\}$:

| $k$ | $k \bmod 7$ | |-----|------------| | 14 | 0 | | 3 | 3 | | 22 | 1 | | 9 | 2 |

All four keys map to distinct buckets, so no collision occurs in this instance. Note that $k = 7$ and $k = 14$ would both map to bucket $0$, illustrating that collisions are unavoidable whenever $|U| > m$.

Key Theorem (Birthday Bound). If $n$ keys are inserted into a table of size $m$ using a perfectly uniform hash function, the probability that at least one collision occurs satisfies

$$\Pr[\text{collision}] \approx 1 - e^{-n(n-1)/(2m)}.$$

In particular, once $n \approx \sqrt{2m \ln 2}$ keys have been inserted, a collision occurs with probability exceeding $\tfrac{1}{2}$. This result, analogous to the classical birthday paradox, explains why even moderate load factors require an efficient collision-resolution strategy such as chaining or open addressing.

Lab Cell.

from sympy import Mod, symbols, latex

k, m = symbols('k m', integer=True)
keys = [14, 3, 22, 9]
modulus = 7

print(f"Table size m = {modulus}")
for key in keys:
    bucket = key % modulus
    print(f"  h({key}) = {key} mod {modulus} = {bucket}")

# Symbolic form
h = Mod(k, m)
print("\nSymbolic hash function: h(k) =", latex(h))

Running this cell prints each bucket assignment and displays the symbolic expression $k \bmod m$ in $\LaTeX$, confirming the hand-computed values above.
