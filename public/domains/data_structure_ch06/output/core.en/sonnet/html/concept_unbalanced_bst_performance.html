Unbalanced Bst Performance

Definition. A binary search tree (BST) is a rooted binary tree in which every node $x$ satisfies the BST property: all keys in the left subtree of $x$ are strictly less than $\text{key}(x)$, and all keys in the right subtree are strictly greater. The height $h$ of a BST is the length of the longest root-to-leaf path. For a tree storing $n$ distinct keys, the worst-case time complexity of search, insertion, and deletion is $\Theta(h)$. An unbalanced BST is one in which $h$ grows super-logarithmically with $n$, degrading these operations well beyond the $O(\log n)$ bound that balanced variants guarantee.

Worked Example. Consider inserting the keys $1, 2, 3, 4, 5$ into an initially empty BST in sorted order. Because each successive key is larger than all existing keys, every new node becomes the right child of the current rightmost leaf. The resulting tree is a right-leaning chain (a degenerate or pathological BST) of height $h = n - 1 = 4$. Searching for the key $5$ requires traversing all five nodes, giving $\Theta(n)$ time rather than the $\Theta(\log n)$ achievable in a balanced tree of the same size.

Key Theorem. (Expected height under random insertion.) If $n$ distinct keys are inserted into an empty BST in a uniformly random order, the expected height satisfies

$$\mathbb{E}[h] \leq 4.311 \ln n + O(1).$$

Thus, random insertion yields $O(\log n)$ expected performance. However, the worst-case height over all insertion orders is $h = n - 1$, achieved by any sorted or reverse-sorted sequence. Since real-world data is rarely uniformly random, relying on an unbalanced BST in production is unsafe; self-balancing trees (AVL, red–black) maintain $h = O(\log n)$ deterministically.

Lab Cell (SymPy).

from sympy import symbols, log, plot

n = symbols('n', positive=True)
worst   = n - 1          # degenerate chain
expected = 4.311 * log(n)  # random-order upper bound
balanced = log(n, 2)     # ideal balanced tree

plot(worst, expected, balanced,
     (n, 2, 64),
     legend=True,
     title='BST Height: Worst vs Expected vs Balanced',
     xlabel='n (number of keys)',
     ylabel='height h')
