Weight Balanced Tree

Definition. A weight-balanced tree (also called a BB[$\alpha$]-tree or bounded-balance tree) is a binary search tree in which balance is maintained not by the height of subtrees but by their sizes. For a node $v$ with left subtree $L$ and right subtree $R$, define the weight of a subtree $T$ as $|T| = $ the number of nodes in $T$. The tree satisfies the weight-balance condition with parameter $\alpha \in \bigl(0, \tfrac{1}{2}\bigr]$ if, for every internal node $v$:

$$\alpha \cdot (|L| + |R| + 1) \;\leq\; |L| + 1 \;\leq\; (1 - \alpha)(|L| + |R| + 1).$$

Equivalently, neither subtree may contain more than a $(1-\alpha)$ fraction of the total nodes rooted at $v$. When $\alpha = \tfrac{1}{4}$, at most $\tfrac{3}{4}$ of all nodes may reside in one child, a commonly used default.

Worked Example. Consider inserting the keys $\{5, 3, 7, 1, 4\}$ in order with $\alpha = \tfrac{29}{100}$ (the classical Nievergelt–Reingold value). After inserting $5, 3, 7$, the root $5$ has $|L|=1$, $|R|=1$, and weight $3$; the balance ratio $\tfrac{2}{3} \approx 0.67 < 1 - \alpha = 0.71$, so balance holds. Inserting $1$ and $4$ yields $|L|=3$, $|R|=1$ at the root, giving ratio $\tfrac{4}{5} = 0.80 > 0.71$. A single right rotation at node $3$ redistributes mass so that both subtrees each hold $2$ nodes, restoring the condition.

Key Theorem. (Logarithmic height) If a binary search tree on $n$ nodes satisfies the weight-balance condition with parameter $\alpha$, its height $h$ satisfies

$$h \;\leq\; \left\lfloor \log_{1/(1-\alpha)} n \right\rfloor.$$

Proof sketch. On any root-to-leaf path, each descent into a child reduces the subtree size by at least a factor of $(1-\alpha)$. Starting from $n$ and multiplying by $(1-\alpha)$ at most $h$ times, one reaches a subtree of size $\geq 1$, giving $n(1-\alpha)^h \geq 1$, hence the bound.

As a consequence, all standard operations—search, insert, delete—run in $O(\log n)$ worst-case time, with rotations triggered at most $O(1)$ amortized per update.

Lab Cell (SymPy).

from sympy import symbols, log, floor, Rational

alpha = Rational(29, 100)
n = symbols('n', positive=True)
height_bound = floor(log(n, 1 / (1 - alpha)))
print("Height bound:", height_bound)
# Evaluate for n = 1000
print("h ≤", floor(log(1000, 1 / (1 - alpha))))

Running this cell yields $h \leq 13$ for $n = 1000$, illustrating the tight logarithmic guarantee that makes weight-balanced trees practical for ordered-map implementations.
