Left Leaning Property

Definition. A left-leaning red-black tree (LLRB tree) is a binary search tree in which every node is colored either red or black, subject to the standard red-black invariants plus one additional structural constraint: the left-leaning property, which requires that every red link in the tree connects a node to its left child. Equivalently, no node may have a red right child. Formally, for every internal node $v$, if the link from $v$ to its right child is red, the tree violates the left-leaning property and must be repaired.

We denote the color of the link from a node $v$ to its parent by $\mathrm{color}(v) \in \{\mathrm{RED}, \mathrm{BLACK}\}$. The left-leaning property states:

$$\forall v \in T,\quad \mathrm{color}(\mathrm{right}(v)) = \mathrm{RED} \implies \bot.$$

This restriction reduces the number of valid tree shapes, simplifying implementation: only two rotation cases (left-rotate and right-rotate) and one color-flip case are needed during insertion, compared with the four cases required by general red-black trees.

Worked Example. Insert the keys $3, 1, 2$ in order into an initially empty LLRB tree.

  • Insert $3$: root, colored black. Tree: $\mathbf{3}$.
  • Insert $1$: placed as left child of $3$ with a red link. Left-leaning property holds.
  • Insert $2$: placed as right child of $1$ with a red link. This creates a red right link at node $1$, violating the left-leaning property. A left-rotation at $1$ is applied, making $2$ the left child of $3$ and $1$ the left child of $2$, both via red links. Now two consecutive red left links exist, so a right-rotation at $3$ is applied, followed by a color-flip. The final tree has $2$ as the black root, with red children $1$ (left) and $3$ (right).

    • Key Theorem (Black-Height Uniformity). In any LLRB tree satisfying the left-leaning property, every root-to-null path contains the same number of black links. Consequently, if the tree holds $n$ keys, its height satisfies $h \leq 2\lfloor \log_2(n+1) \rfloor$, guaranteeing $O(\log n)$ search, insertion, and deletion.

    Proof sketch. Because red links are left-leaning and no two consecutive red links may appear on any root-to-leaf path (inherited from the standard red-black invariant), at most every other link on any path is red. Uniformity of black-height then bounds the total path length by twice the black-height, which is $\lfloor \log_2(n+1) \rfloor$.

    Lab Cell (SymPy).

    from sympy import floor, log, symbols

n = symbols('n', positive=True, integer=True)
black_height = floor(log(n + 1, 2))
height_bound  = 2 * black_height

# Evaluate for n = 15 (a perfect binary tree)
print(f"Black-height (n=15): {black_height.subs(n, 15)}")   # 4
print(f"Height bound  (n=15): {height_bound.subs(n, 15)}")   # 8

    Running this cell confirms that a 15-node LLRB tree has a black-height of $4$ and a worst-case height of $8$, consistent with the theorem.
