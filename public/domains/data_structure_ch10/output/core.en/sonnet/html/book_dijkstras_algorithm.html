Concept Book: Dijkstras Algorithm

Payoff

What Dijkstra's Algorithm Achieves

Every concept developed in this text — weighted graphs, priority queues, greedy selection, and the relaxation of edge weights — converges here. Dijkstra's algorithm solves the single-source shortest-path problem: given a weighted directed graph $G = (V, E, w)$ with non-negative edge weights $w : E \to \mathbb{R}_{\geq 0}$ and a designated source vertex $s \in V$, it computes, for every vertex $v \in V$, the minimum-cost path $\delta(s, v) = \min_{\pi: s \rightsquigarrow v} \sum_{e \in \pi} w(e)$. No heuristic is required; the answer is exact and provably optimal.

Why This Is the Natural Endpoint

Shortest-path problems are not a narrow curiosity. They are the underlying structure of a remarkable range of questions that initially appear unrelated: How does a packet find the least-latency route across the internet? Which sequence of chemical reactions minimises energy expenditure? What is the cheapest itinerary connecting a set of cities? Each question, once modelled as a weighted graph, admits an exact answer via Dijkstra's algorithm. The algorithm is therefore not merely a clever trick; it is a translation layer between informal optimisation intuitions and rigorous computation.

Correctness at a Glance

The algorithm maintains a set $S$ of settled vertices whose shortest distances are finalised, and a priority queue $Q$ of candidates ordered by their current tentative distance $d[v]$. At each step, it extracts the vertex $u$ with minimum $d[u]$, adds $u$ to $S$, and relaxes each outgoing edge $(u, v)$: if $d[u] + w(u,v) < d[v]$, update $d[v]$. The key invariant — proved by induction on $|S|$ — is that when a vertex is extracted from $Q$, its tentative distance equals its true shortest-path distance $\delta(s, u)$. Non-negativity of weights is precisely the condition that prevents a later edge from improving a settled vertex's distance, making the greedy extraction safe.

A Worked Instant

Consider the graph with vertices $\{A, B, C, D\}$, source $A$, and edges $A \to B$ (weight 1), $A \to C$ (weight 4), $B \to C$ (weight 2), $B \to D$ (weight 5), $C \to D$ (weight 1). Initialise $d = \{A:0,\, B:\infty,\, C:\infty,\, D:\infty\}$. Extract $A$; relax to $d[B]=1$, $d[C]=4$. Extract $B$; relax to $d[C]=3$, $d[D]=6$. Extract $C$; relax to $d[D]=4$. Extract $D$. Final distances: $\delta(A,D) = 4$ via the path $A \to B \to C \to D$.

Lab Cell

import heapq

def dijkstra(graph, source):
    dist = {v: float('inf') for v in graph}
    dist[source] = 0
    pq = [(0, source)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, w in graph[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                heapq.heappush(pq, (dist[v], v))
    return dist

G = {'A': [('B',1),('C',4)], 'B': [('C',2),('D',5)],
     'C': [('D',1)], 'D': []}
print(dijkstra(G, 'A'))   # {'A': 0, 'B': 1, 'C': 3, 'D': 4}
