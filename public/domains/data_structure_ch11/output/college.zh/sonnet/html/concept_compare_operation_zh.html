比较运算(Compare Operation)

定义

比较运算是一个基本操作 $\text{compare}(a, b)$,它接收两个可比较的对象,返回一个整数,用符号表示二者的顺序关系:

$$ \text{compare}(a,b)= \begin{cases} <0, & a0, & a>b \end{cases} $$

关键在于:调用者只关心返回值的符号,不应依赖具体数值(例如 $-1$ 与 $-37$ 含义相同)。几乎所有排序、查找与优先队列算法,都只通过这一原语来获知元素之间的顺序。

要使 compare 行为正确,它必须定义一个全序,即满足:

  • 反对称性:$\text{compare}(a,b)$ 与 $\text{compare}(b,a)$ 符号相反;
  • 传递性:若 $a\le b$ 且 $b\le c$,则 $a\le c$;
  • 完全性:任意两个元素都可以比较。

    • 例题

    用 Python 为"先按年级、再按姓名"比较学生:

    def compare(a, b):
    if a.grade != b.grade:
        return a.grade - b.grade      # 年级低者在前
    if a.name < b.name:
        return -1
    if a.name > b.name:
        return 1
    return 0

    设 $a=(\text{高一},\text{李})$,$b=(\text{高二},\text{王})$。年级不同,返回 $\text{高一}-\text{高二}<0$,因此 $a字典序比较。

    问题求解应用

    问题 1:二分查找。 在有序数组中查找目标 $t$,每一步计算 $c=\text{compare}(t,\,A[m])$:

  • $c=0$:找到;
  • $c<0$:在左半部分继续;
  • $c>0$:在右半部分继续。

    • 每次比较使搜索范围减半,递推式为 $T(n)=T(n/2)+O(1)$,故 $T(n)=O(\log n)$。

    问题 2:下界。 仅依靠 compare 的排序算法,其决策树至少需要 $n!$ 个叶子,高度 $h$ 满足 $2^h\ge n!$,所以

    $$ h\ge \log_2(n!)=\Theta(n\log n). $$

    因此基于比较的排序不可能优于 $O(n\log n)$。

    问题 3:常见陷阱。 用减法实现 compare 可能整数溢出:例如在 32 位整数中,$a=2^{30}\cdot 2$ 与 $b=-1$ 相减会得到错误符号。更稳妥的写法是:

    return (a > b) - (a < b)   # 只返回 -1, 0, 1

    另外,浮点数中的 NaN 与任何数比较都不成立,破坏了完全性,排序前需要先行处理。

    小结: compare 只需返回符号,但它必须满足全序的三条性质;一旦违反,排序与查找的正确性都将失去保证。
