Integer Sorting Via Indexing

Definition. Let $A = [a_1, a_2, \ldots, a_n]$ be a sequence of integers drawn from a bounded range $[0, k-1]$ for some positive integer $k$. Sorting by indexing (more commonly called counting sort) exploits the discrete structure of the domain: rather than comparing elements pairwise, we construct a frequency array $C$ of length $k$, where $C[v]$ records the number of times value $v$ appears in $A$. A prefix-sum pass then converts $C$ into a position array, and a final sweep reconstructs the sorted output in $O(n + k)$ time — a decisive improvement over the $O(n \log n)$ comparison lower bound when $k = O(n)$.

Worked Example. Let $A = [3, 1, 0, 1, 3, 2]$ with $k = 4$.

  • Count. Initialize $C = [0, 0, 0, 0]$. Scan $A$: $C[3]{+}{=}1$, $C[1]{+}{=}1$, $C[0]{+}{=}1$, $C[1]{+}{=}1$, $C[3]{+}{=}1$, $C[2]{+}{=}1$, yielding $C = [1, 2, 1, 2]$.
  • Prefix sum. Set $C[j] \leftarrow C[j] + C[j-1]$ for $j = 1, \ldots, 3$: $C = [1, 3, 4, 6]$. Now $C[v]$ is the number of elements $\leq v$, i.e., the last output index (1-based) for value $v$.
  • Place. Traverse $A$ right to left. For each $a_i$, place it at output position $C[a_i]$, then decrement $C[a_i]$. The result is $[0, 1, 1, 2, 3, 3]$.

    • Key Theorem (Correctness and Stability). After the prefix-sum step, $C[v] - C[v-1]$ equals the count of occurrences of $v$. The right-to-left placement guarantees that equal elements retain their original relative order — a property called stability — which makes counting sort suitable as a subroutine in radix sort.

    Complexity. Time: $O(n + k)$. Space: $O(n + k)$ auxiliary. When $k = O(n)$, this is linear overall.

    Lab Cell.

    from sympy import symbols, Function
A = [3, 1, 0, 1, 3, 2]; k = 4
C = [0] * k
for v in A:
    C[v] += 1
for j in range(1, k):
    C[j] += C[j-1]
out = [0] * len(A)
for v in reversed(A):
    C[v] -= 1
    out[C[v]] = v
print(out)  # [0, 1, 1, 2, 3, 3]
