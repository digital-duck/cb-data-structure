终点:为什么是 BFS 最短路径

在无权图 $G=(V,E)$ 中,从源点 $s$ 到顶点 $v$ 的最短路径是边数最少的路径,其长度记为 $d(s,v)$。广度优先搜索(BFS)用一个先进先出队列逐层向外扩展:先访问距离为 0 的 $s$,再访问距离为 1 的邻居,然后是距离为 2 的顶点,依此类推。

正确性定理。 BFS 首次到达顶点 $v$ 时所赋的层号恰好等于 $d(s,v)$。

证明思路。 队列中的距离值始终单调不减,且任意时刻最多只含两个相邻的层号 $k$ 与 $k+1$。若 $v$ 的真实距离为 $k+1$,则它必有一个距离为 $k$ 的邻居 $u$。$u$ 出队时会发现 $v$ 尚未访问,于是令 $d(v)=k+1$。更小的值不可能出现,因为那要求 $v$ 在更早的层中被发现。$\square$

时间复杂度为 $O(|V|+|E|)$,每个顶点和每条边至多处理一次。

它之所以是自然的终点,是因为前面学过的概念都汇聚于此。图的表示提供邻接结构,队列提供处理顺序,"已访问"集合避免重复,层的概念把"搜索"变成"度量"。只需再增加一个前驱数组 $\pi(v)$,记录是谁发现了 $v$,就能从 $v$ 沿 $\pi$ 回溯到 $s$,还原出一条实际的最短路径。

例题

设图的邻接表为:$A:\{B,C\}$,$B:\{D\}$,$C:\{D,E\}$,$D:\{F\}$,$E:\{F\}$,求 $A\to F$ 的最短路径。

  • 队列 $[A]$,$d(A)=0$。
  • 取出 $A$,加入 $B,C$,令 $d=1$,$\pi(B)=\pi(C)=A$。
  • 取出 $B$,加入 $D$,令 $d(D)=2$,$\pi(D)=B$。
  • 取出 $C$,$D$ 已访问;加入 $E$,令 $d(E)=2$,$\pi(E)=C$。
  • 取出 $D$,加入 $F$,令 $d(F)=3$,$\pi(F)=D$。

    • 回溯得到 $F\leftarrow D\leftarrow B\leftarrow A$,即最短路径 $A\to B\to D\to F$,长度为 3。

    from collections import deque
def bfs_path(adj, s, t):
    pi, q = {s: None}, deque([s])
    while q:
        u = q.popleft()
        if u == t: break
        for v in adj[u]:
            if v not in pi:
                pi[v] = u; q.append(v)
    path = []
    while t is not None: path.append(t); t = pi.get(t)
    return path[::-1]

    应用领域

    本节没有列出具体的应用领域,但这一算法几乎可以放进任何"状态之间一步一步转移"的问题:

  • 网络与社交图: 度数分隔("六度分隔")就是两点间的 BFS 距离。
  • 导航与地图: 在各边代价相同的路网中,BFS 直接给出最少换乘或最少路段数。
  • 谜题与游戏: 把每种局面当作顶点、每次合法操作当作边,BFS 给出最少步数,例如魔方、滑块和迷宫。
  • 知识图谱: 在概念依赖图中,最短的先修链就是一条从已知概念到目标概念的 BFS 路径。

    • 共同的建模步骤是:确定顶点是什么,确定边代表什么操作,再确认每条边的代价相同。若代价不同,就要改用 Dijkstra 算法。
