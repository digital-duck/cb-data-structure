通过广度优先搜索求最短路径

定义

设无权图 $G=(V,E)$,$r\in V$ 为源点。从 $r$ 到顶点 $j$ 的最短路径是边数最少的路径,其长度记为 $d(j)$。

广度优先搜索(BFS)按"层"扩展:先访问距 $r$ 为 $0$ 的点,再访问距离为 $1$ 的点,依此类推。因此每个顶点首次被发现时,所用的边数恰为它到 $r$ 的最短距离。

为了还原路径,我们为每个顶点记录前驱数组 $p$:当顶点 $v$ 的邻居 $w$ 第一次被发现时,令

$$p[w]=v,\qquad d(w)=d(v)+1.$$

源点满足 $p[r]=\text{None}$。

from collections import deque

def bfs(adj, r):
    p = {r: None}
    d = {r: 0}
    q = deque([r])
    while q:
        v = q.popleft()
        for w in adj[v]:
            if w not in p:        # 首次发现
                p[w] = v
                d[w] = d[v] + 1
                q.append(w)
    return p, d

def path(p, j):
    if j not in p:
        return None               # 不可达
    res = []
    while j is not None:
        res.append(j)
        j = p[j]
    return res[::-1]

BFS 的时间复杂度为 $O(|V|+|E|)$,每个顶点至多入队一次,每条边至多被检查常数次。

worked example

图的邻接表为:$A:\{B,C\}$,$B:\{A,D\}$,$C:\{A,D,E\}$,$D:\{B,C,F\}$,$E:\{C,F\}$,$F:\{D,E\}$。取 $r=A$。

| 出队顶点 | 新发现的顶点 | 记录 | |---|---|---| | $A$ | $B,C$ | $p[B]=p[C]=A$ | | $B$ | $D$ | $p[D]=B$ | | $C$ | $E$ | $p[E]=C$($D$ 已被发现) | | $D$ | $F$ | $p[F]=D$ |

还原 $A$ 到 $F$ 的路径:$F\to p[F]=D\to p[D]=B\to p[B]=A$,反转得 $A,B,D,F$,长度 $d(F)=3$。注意 $E$ 也能到达 $F$,但 $D$ 先出队,所以 $p[F]$ 不会被覆盖;这条路径同样长度为 3,最短路径不一定唯一。

BFS 树:每条边由 $p$ 数组确定,从任意顶点沿箭头反向走到 $A$ 即得最短路径。

问题求解应用

问题:迷宫是 $n\times n$ 的网格,求从起点到出口的最少步数及一条具体路线。

解法:把每个空格看作顶点,相邻空格之间连边,这就化为无权图上的最短路径问题。

  • 从起点运行 BFS,记录 $p$ 和 $d$。
  • 若出口不在 $p$ 中,则无解。
  • 否则 $d(\text{出口})$ 即最少步数,用 path(p, 出口) 还原路线。

    • 正确性要点:BFS 队列中顶点的距离单调不减,所以首次发现某点时的距离就是最小距离(对 $d$ 归纳可证)。此结论依赖边权相同;若边带有不同权重,需改用 Dijkstra 算法。

    复杂度:网格有 $n^2$ 个顶点、至多 $2n(n-1)$ 条边,总时间为 $O(n^2)$,路径还原再花 $O(d(j))$。

    常见错误:在顶点出队时才标记"已访问"会让同一顶点重复入队,既浪费时间,也可能覆盖 $p$。应在发现时就标记,如上面 if w not in p 所做的那样。
