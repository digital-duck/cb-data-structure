栈

定义。 栈(stack)是一种后进先出(LIFO, Last-In-First-Out)的线性集合。它只允许在同一端(栈顶)操作,核心操作有三个:

  • push(x):把元素 $x$ 压入栈顶;
  • pop():弹出并返回栈顶元素;
  • peek():查看栈顶元素但不删除。

    • 在合适的实现(如数组末尾或链表头)下,三个操作的时间复杂度均为 $O(1)$。递归之所以能工作,正是因为系统维护了一个"调用栈";而显式使用栈,就是把这个隐含的结构交到自己手中,从而自主控制遍历顺序,并避免递归过深导致的栈溢出。

    例题:用栈做二叉树的前序遍历。 考虑二叉树:根为 $A$,左孩子为 $B$,右孩子为 $C$;$B$ 的左孩子为 $D$,右孩子为 $E$。

    算法:先把根压栈;每次弹出一个节点并访问,然后先压右孩子,再压左孩子(这样左孩子后进先出,会先被处理)。

    | 步骤 | 弹出并访问 | 压入后的栈(右端为栈顶) | |---|---|---| | 初始 | — | $[A]$ | | 1 | $A$ | $[C, B]$ | | 2 | $B$ | $[C, E, D]$ | | 3 | $D$ | $[C, E]$ | | 4 | $E$ | $[C]$ | | 5 | $C$ | $[\ ]$ |

    访问顺序为 $A, B, D, E, C$,正是前序遍历。

    def preorder(root):
    result, stack = [], [root]
    while stack:
        node = stack.pop()
        if node is None:
            continue
        result.append(node.val)
        stack.append(node.right)   # 先压右
        stack.append(node.left)    # 后压左,先被弹出
    return result

    问题求解应用。 栈不仅能改写递归,还能改变遍历的性质:

  • 深度优先搜索(DFS):在图上把"前序遍历"中的左右孩子换成所有未访问的邻居即可。若把栈换成先进先出的队列,同一段代码就变成广度优先搜索(BFS)——仅靠更换容器就能切换遍历顺序。
  • 括号匹配:遇到左括号压栈,遇到右括号则弹出并检查是否配对。对 {[()]} 逐字符处理,栈在末尾为空则合法;若中途弹空或结尾非空,则不合法。
  • 深度限制:Python 默认递归深度约 1000 层;对一条含 $10^5$ 个节点的链状树,递归会崩溃,而显式栈只受内存限制。

    • 复杂度分析。 每个节点恰好入栈、出栈各一次,总时间为 $O(n)$;额外空间最坏为 $O(n)$(链状树),平衡树时仅为 $O(h)$,其中 $h$ 为树高。
