What cycle detection via DFS achieves. A cycle in a directed graph $G = (V, E)$ is a sequence of distinct vertices $v_0, v_1, \ldots, v_k$ with $k \geq 1$ such that $(v_i, v_{i+1}) \in E$ for $0 \leq i < k$ and $(v_k, v_0) \in E$. Cycle detection via depth-first search (DFS) determines, in $\Theta(|V| + |E|)$ time, whether any such sequence exists. The algorithm colors each vertex white (undiscovered), gray (in the current DFS stack), or black (fully processed). A back edge — an edge $(u, v)$ encountered when $v$ is gray — is the exact witness of a cycle, because it closes a path that is already open on the recursion stack. This coloring invariant makes DFS the canonical tool: unlike BFS, the stack structure of DFS naturally mirrors the "currently open path" concept that a cycle requires.

A worked example. Consider $V = \{A, B, C\}$ with edges $A \to B$, $B \to C$, $C \to A$. Beginning DFS at $A$: color $A$ gray, recurse to $B$ (gray), recurse to $C$ (gray). Inspecting the neighbor of $C$ reveals $A$ is still gray — a back edge is found, confirming a cycle $A \to B \to C \to A$.

Key theorem. A directed graph $G$ is acyclic if and only if a DFS of $G$ produces no back edges.

Proof sketch. ($\Rightarrow$) If DFS finds a back edge $(u, v)$, the gray path from $v$ to $u$ together with this edge forms a cycle. ($\Leftarrow$) If $G$ contains a cycle $v_0, \ldots, v_k, v_0$, then whichever $v_i$ is discovered first will have $v_{i-1}$ (mod $k+1$) still gray when that edge is traversed. $\square$

Lab cell (SymPy / NetworkX).

import networkx as nx

G = nx.DiGraph([("A","B"), ("B","C"), ("C","A")])
print("Has cycle:", not nx.is_directed_acyclic_graph(G))
# Inspect back edges manually
for u, v, d in nx.dfs_labeled_edges(G, source="A"):
    if d == "forward" or d == "nontree":
        print(f"  edge {u}→{v}: {d}")

Why this is the natural endpoint. Every concept in this chapter — graph traversal, DFS timestamps, tree versus non-tree edges — was scaffolding toward one diagnostic question: does a dependency, process, or proof chain loop back on itself? The back-edge criterion answers that question with a single linear-time pass, and the answer cascades into correctness guarantees for topological sorting, deadlock analysis in concurrent systems, and consistency checking in knowledge graphs.
