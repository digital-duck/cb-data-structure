Shortest Path Via Bfs

Definition. Let $G = (V, E)$ be an unweighted, undirected graph where every edge carries unit cost. The shortest path between two vertices $s, t \in V$ is a walk $s = v_0, v_1, \ldots, v_k = t$ with $\{v_{i-1}, v_i\} \in E$ for all $i$, minimising the hop count $k$. Breadth-First Search (BFS) discovers vertices in non-decreasing order of their distance from the source $s$. Formally, BFS maintains a FIFO queue $Q$ and a distance array $d: V \to \mathbb{N}_0 \cup \{\infty\}$, initialised as $d(s) = 0$ and $d(v) = \infty$ for $v \neq s$. At each step the front vertex $u$ is dequeued; for every neighbour $w$ with $d(w) = \infty$ the algorithm sets $d(w) = d(u) + 1$, records $\pi(w) = u$ (the predecessor), and enqueues $w$. The shortest path to any vertex $t$ is then reconstructed by following the predecessor chain $t \to \pi(t) \to \cdots \to s$.

Worked Example. Consider the graph $G$ with $V = \{A, B, C, D, E\}$ and edges $\{A\text{-}B,\; A\text{-}C,\; B\text{-}D,\; C\text{-}D,\; D\text{-}E\}$. Running BFS from $s = A$:

| Step | Queue | Vertex processed | $d$ updated | |------|-------|-----------------|-------------| | 0 | $[A]$ | — | $d(A)=0$ | | 1 | $[B, C]$ | $A$ | $d(B)=d(C)=1$ | | 2 | $[C, D]$ | $B$ | $d(D)=2$ | | 3 | $[D]$ | $C$ | $D$ already visited | | 4 | $[E]$ | $D$ | $d(E)=3$ |

The shortest path from $A$ to $E$ has length $d(E) = 3$, realised by $A \to B \to D \to E$ (or $A \to C \to D \to E$).

Key Theorem (Correctness of BFS). For any unweighted graph $G$ and source $s$, upon termination of BFS, $d(v)$ equals the true shortest-path distance $\delta(s, v)$ for every $v \in V$.

Proof sketch. By induction on $k$: BFS enqueues all vertices at distance $k$ before any at distance $k+1$ (the FIFO property preserves layer order). Hence the first time a vertex $v$ is dequeued it carries the minimum hop count, and no shorter route can exist. $\square$

Time complexity: $O(|V| + |E|)$, since each vertex and edge is visited at most once.

Lab Cell (SymPy / NetworkX).

import networkx as nx

G = nx.Graph()
G.add_edges_from([("A","B"),("A","C"),("B","D"),("C","D"),("D","E")])

path   = nx.shortest_path(G, source="A", target="E", method="bfs")
length = nx.shortest_path_length(G, source="A", target="E")

print(f"Shortest path : {path}")    # ['A', 'B', 'D', 'E']
print(f"Path length   : {length}")  # 3

Running this cell confirms $\delta(A, E) = 3$ and returns one optimal route; modify the edge list to explore how adding a shortcut edge reduces the BFS diameter.
