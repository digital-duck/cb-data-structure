收获(Payoff)

van Emde Boas 树达成了什么

在整个学习过程中,我们反复面对同一个问题:在全域 $U=\{0,1,\dots,u-1\}$ 中维护一个动态集合,并支持插入、删除、查找、后继、前驱。平衡二叉搜索树给出 $O(\log n)$,其下界来自比较模型。van Emde Boas(vEB)树跳出了这个模型:它利用键是整数这一额外结构,把复杂度降到

$$T(u)=T(\sqrt{u})+O(1)\;\Longrightarrow\;T(u)=O(\log\log u).$$

换元 $m=\log u$,递推变为 $S(m)=S(m/2)+O(1)$,解得 $S(m)=O(\log m)$,这正是 $O(\log\log u)$ 的来源。

它之所以是自然的终点,是因为它把前面的几个思想合在了一起。

  • 位向量:提供 $O(1)$ 的成员查询。
  • 全域分块:把 $u$ 拆成 $\sqrt{u}$ 个大小为 $\sqrt{u}$ 的簇。
  • 摘要结构:递归地记录哪些簇非空。
  • 缓存最小值/最大值:让每层只做一次递归调用。

    • 最后一点很关键。如果 insert 在每层调用两次,递推就变成 $T(u)=2T(\sqrt{u})+O(1)$,结果是 $O(\log u)$,优势全部丢失。

    工作示例:后继查询

    设 $u=16$,集合为 $\{2,3,7,10,13\}$。查询 $\operatorname{succ}(3)$。

  • 令 $x=3=(0,3)$,即簇号 $\text{high}(x)=0$,簇内位置 $\text{low}(x)=3$。
  • 查看簇 0 的最大值:$\max=3\not>3$,因此簇内没有更大的元素。
  • 在摘要结构中求 $\operatorname{succ}(0)=1$,得到下一个非空簇 $1$(对应 $\{7\}$)。
  • 返回簇 1 的最小值,$\text{index}(1,3)=1\cdot4+3=7$。

    • 整个过程只进行一次真正的递归调用(步骤 2 的判断是 $O(1)$ 的),所以总代价为 $O(\log\log u)$。

    与各应用领域的联系

    本节未列出具体应用领域,下面说明 vEB 的思想通常用在哪些场景。

  • 网络路由与 IP 查找:最长前缀匹配需要在整数键上做后继/前驱,vEB 的思想(分层前缀)是其中的核心。
  • 事件驱动仿真与优先队列:时间戳是有界整数时,extract-min 和 decrease-key 都可以在 $O(\log\log u)$ 内完成。
  • 整数图算法:用它实现 Dijkstra 的优先队列,当边权为整数时可获得 $O(m\log\log C)$ 的性质。
  • 计算几何中的扫描线:坐标离散化之后,可以用它快速维护活跃集合。

    • 注意与权衡

    标准 vEB 树占用 $O(u)$ 空间,当 $u\gg n$ 时代价很高。常见的补救方法有两种:用哈希表只存储非空簇,把空间降到 $O(n)$(期望);或者使用 x-fast / y-fast trie,在保持 $O(\log\log u)$ 的同时让空间接近线性。
