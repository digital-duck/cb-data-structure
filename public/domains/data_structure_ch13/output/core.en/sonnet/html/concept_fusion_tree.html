Fusion Tree

Definition

A fusion tree is a search tree data structure designed for the integer predecessor problem over a universe $\{0, 1, \ldots, U-1\}$. Introduced by Fredman and Willard (1993), it stores a set $S$ of $n$ integers drawn from $w$-bit machine words, where $w$ denotes the native word size of the underlying hardware. The structure achieves query time $O(\log n / \log w)$ by replacing naive binary comparisons with parallel bitwise operations that compare multiple keys simultaneously within a single word.

A fusion tree partitions its keys into a $B$-ary trie where each internal node holds up to $B = w^{1/5}$ keys. Within each node, the $B$ stored keys are compressed into a single machine word via a sketching function $\text{sketch}: \{0,1\}^w \to \{0,1\}^{B^4}$ that retains only the bits distinguishing the node's keys from one another — called the distinguishing bits. A query key $x$ is sketched identically and compared against all $B$ node keys in $O(1)$ word-RAM operations using a carefully constructed parallel bitmask.

Worked Example

Suppose $w = 16$ and a node stores $B = 3$ keys: $k_1 = 0011$, $k_2 = 0110$, $k_3 = 1010$ (in 4-bit shorthand for illustration). The distinguishing bits are positions $\{0, 2, 3\}$ (bits that differ across at least one pair). The sketch maps each key by extracting these bits: $\text{sketch}(k_1) = 010$, $\text{sketch}(k_2) = 110$, $\text{sketch}(k_3) = 100$. These three 3-bit sketches are packed into a single integer

$$ M = \text{sketch}(k_1) \;\Vert\; \text{sketch}(k_2) \;\Vert\; \text{sketch}(k_3) = 010\,110\,100. $$

For a query $x = 0101$, compute $\text{sketch}(x) = 101$ and replicate it as $X = 101\,101\,101$. The predecessor rank of $x$ among the node's keys is recovered from the subtraction $X - M$ in $O(1)$ via the sign bits of each packed field, locating the correct child pointer without a single explicit comparison.

Key Theorem

Theorem (Fredman–Willard, 1993). A fusion tree storing $n$ integers from a $w$-bit universe supports predecessor queries and insertions in $O(\log n / \log w)$ worst-case time on the word-RAM model with word size $w \geq \log^2 n$.

Setting $w = \Theta(\log n)$ yields the celebrated $O(\log n / \log \log n)$ query bound, which breaks the $\Omega(\log n)$ comparison-tree barrier and remains the asymptotically fastest known deterministic predecessor structure for polynomial universes.

Lab Cell

import sympy as sp

w, B_exp = sp.symbols('w B_exp', positive=True)

# Node branching factor as a function of word size
B = w ** sp.Rational(1, 5)

# Query time: height of B-ary tree over n keys
n = sp.Symbol('n', positive=True)
height = sp.log(n, B)          # log_B(n)
height_simplified = sp.simplify(height)

print("Branching factor B =", B)
print("Tree height       =", sp.simplify(height))

# Evaluate at w = 64, n = 10**6
vals = {w: 64, n: 10**6}
print("Height (w=64, n=10^6) ≈",
      float(height_simplified.subs(vals).evalf()), "levels")
