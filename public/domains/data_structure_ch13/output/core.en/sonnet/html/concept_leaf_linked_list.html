Leaf Linked List

Definition

Let $T$ be a rooted tree whose internal nodes serve solely as routing structures and whose leaf nodes store actual data. A leaf linked list is an augmented representation of $T$ in which every leaf node carries an additional pointer to the next leaf in left-to-right (in-order) traversal order, forming a singly linked list $L = \langle \ell_1, \ell_2, \ldots, \ell_n \rangle$ over the leaf set $\mathcal{L}(T)$.

Formally, for each leaf $\ell_i \in \mathcal{L}(T)$, define

$$\ell_i.\texttt{next} = \begin{cases} \ell_{i+1} & \text{if } i < n, \\ \texttt{nil} & \text{if } i = n. \end{cases}$$

The structure supports two independent access patterns: hierarchical lookup through the tree edges and sequential scan through the $\texttt{next}$ chain, without requiring re-traversal of interior nodes.

Worked Example

Consider the binary search tree built from the key sequence $\{3, 1, 4, 1, 5\}$ (duplicates resolved left). After insertion the leaves are, in in-order, $1, 1, 3, 4, 5$. Augmenting with $\texttt{next}$ pointers gives

$$\ell_1(1) \xrightarrow{\texttt{next}} \ell_2(1) \xrightarrow{\texttt{next}} \ell_3(3) \xrightarrow{\texttt{next}} \ell_4(4) \xrightarrow{\texttt{next}} \ell_5(5) \xrightarrow{\texttt{next}} \texttt{nil}.$$

A range query $[2, 4]$ locates $\ell_3$ in $O(\log n)$ tree time and then streams $\ell_3, \ell_4$ through the linked list in $O(k)$ time, where $k = 2$ is the output size.

Key Theorem

Theorem (Range-Query Complexity). Let $T$ be a balanced binary search tree on $n$ keys augmented as a leaf linked list. A range query $[a, b]$ returning $k$ leaves executes in $O(\log n + k)$ time.

Proof sketch. The left boundary $a$ is located by a standard tree search in $O(\log n)$. Each subsequent leaf in $[a, b]$ is reached by a single $\texttt{next}$ dereference in $O(1)$; there are exactly $k$ such steps. Total cost is $O(\log n) + O(k) = O(\log n + k)$. $\square$

The bound is optimal: $\Omega(\log n)$ is required for locating the start, and $\Omega(k)$ is unavoidable for reading $k$ outputs.

Lab Cell

from sympy import symbols, Rational

# Represent leaves as (key, next_index) pairs
leaves = [(1, 1), (1, 2), (3, 3), (4, 4), (5, None)]

def range_scan(leaves, lo, hi):
    # Locate first leaf >= lo (simulating O(log n) tree descent)
    start = next((i for i, (k, _) in enumerate(leaves) if k >= lo), None)
    result = []
    idx = start
    while idx is not None:
        key, nxt = leaves[idx]
        if key > hi:
            break
        result.append(key)
        idx = nxt
    return result

print(range_scan(leaves, 2, 4))   # Expected: [3, 4]

Running this cell confirms that only the leaves satisfying the predicate are visited, illustrating the $O(\log n + k)$ claim in a directly inspectable form.
